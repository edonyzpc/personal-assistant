# 防御边界证据链

本参考只在候选涉及生产防御、状态表达或测试 seam 时读取。结论必须来自当前代码和
契约，不能用形状相似性或本文件替代追溯。

## 有效证据链

| 追溯点 | 要核实的事实 | 裁决含义 |
| --- | --- | --- |
| 输入来源 | 来自用户/provider、文件、网络、持久或同步状态、外部进程、跨树交接，还是受控内部构造？ | 外部与持久输入需要真实边界；受控内部对象仍要证明构造后不可变且无绕过入口。 |
| 首次准入与 owner | 谁在哪个入口校验什么；成功后建立什么保证；是否存在动态、公开、宿主或兼容入口绕过？ | 明确单一 owner 后，重复检查才可能简化；入口覆盖不完整时保留分层保护。 |
| 保证有效区间 | 到当前检查之间是否发生序列化、类型断言、动态调用、别名或可变状态、`await`、重入、权限撤销、资源替换？ | 这些形状只是线索；只有实际状态变更、重入或撤销/替换可能影响该保证时才要求重查。纯 `await` 期间保证不可变且入口不可绕过时，上游保证可延续。 |
| 当前效果 | guard/catch/fallback/retry 防哪个具体错误；改变错误类别、传播、副作用、时序、恢复或用户负担？ | 有可观察效果就是行为候选，不是无操作清理；效果等价要有证据。 |
| 独立必要性 | 它是唯一保护点、不同层必要复核，还是同一 owner 内等价重复？ | 前两者保留；最后一项可提出局部简化。 |
| 简化后果 | 删除、合并、迁移到入口或收敛状态后，哪些契约仍成立；由什么事实和测试证明？ | 无法证明承接时待查或保留；不为简化新建通用框架。 |

## 状态表达与 owner 根因

先问复杂防御是否来自状态表达或职责分散。例如 `ready` 与可空资源分离可能迫使多处
处理“ready 但资源缺失”等无效组合；若真实合法状态、构造/迁移入口、错误传播和相关测试
都已核实，可在既有 owner 内收敛表达。不要把每个 guard 机械迁移到入口。

局部结构简化的前提：

- 枚举或对象表达能覆盖已核实的合法状态，并说明旧状态如何迁移；
- 所有真实入口使用新保证，期间不存在可绕过的可变性或异步失效；
- 删除的重复检查无独立可观察效果，必要错误类别和恢复语义不变；
- 相关测试同步迁移，且不靠弱化断言换绿灯。

没有当前问题证据时不做类型重构，不引入状态机框架，也不用 TypeScript 类型替代外部
解析、实际构造/迁移入口、可变性检查或异步失效检查。

## 必要边界反例

以下保护默认不能按重复、内部-only 或“类型不允许”删除：

- 首次解析用户、provider、文件、网络或外部进程输入；
- 旧格式、持久状态或同步状态的兼容与迁移验证；
- 跨 `await` 时取消、权限或资源实际可能变化后的重查；
- 真实并发准入、幂等或 at-most-once 副作用；
- 资源身份、生命周期、释放和撤销；
- 协议、注册表、宿主命令、公开导出、反射/动态调用和 Community/发布契约；
- 现行领域契约明确要求的保护。

公开接口没有仓内调用者不等于废弃；测试专用导出也不能只凭“只有测试在用”删除。必须
检查实际注册、宿主、动态消费、兼容路径和契约证据；一次文本搜索不能证明入口不存在。
反之，测试里用 `as any` 构造的内部不可能状态，不能倒推生产必须新增防御；来自真实
外部或旧状态的同类输入也不能因类型声明而忽略。

## Guard、catch、fallback 与 retry

- **Guard**：说明拒绝的具体输入、拒绝时机和副作用。把检查移到入口须证明入口覆盖完整、
  拒绝时机等价且不会先产生部分副作用。
- **Catch**：边界错误转换或用户可理解降级可能必要；捕获内部错误并返回空结果可能隐藏
  缺陷。比较删除前后的公开错误类别、日志、恢复和重试语义。
- **Fallback**：区分契约允许的默认值、授权替代路径和掩盖故障。不能让失败被吞掉后仍
  表现为成功交付。
- **Retry/cancel**：保留取消、撤销、退避和至少/至多一次语义。不能用增加 timeout/retry
  或强制退出来换取测试绿灯。
- **包装与抽象**：无行为转发可简化；但授权顺序、参数兼容、副作用次数、资源生命周期
  或唯一接线本身可能是契约。

涉及 Agent/runtime/command 时，先应用
[Command Architecture Contract](../../../../docs/architecture/pa-agent-architecture-plan.md#command-architecture-contract)；
Memory/VSS 按 [AGENTS](../../../../AGENTS.md#architecture-rules) 读取对应领域权威。输出
裁决时分别写：证据、建议、所需授权、剩余风险和验证；不能把待查包装成已证明等价。
