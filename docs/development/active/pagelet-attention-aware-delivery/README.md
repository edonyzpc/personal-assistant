## Outcome And Boundary

- Outcome: 已实际看过的同内容 Recall/Recap 不再主动重复；空态说明看过一次后，Pet
  短点打开 Capture / Review / Discover Action Ring。
- Delivery class: L3
- Explicit non-goals: 不做跨 kind、近语义或跨设备去重；不隐藏显式运行/导航结果；
  不新增历史生成卡仓库、Pet 状态、provider call、写入动作或同步 setting。
