### Learning plan.md

```markdown
# Learning plan (fictional example)

Goal: make one bar chart this week using fictional data.
Decided: 30 minutes on Wednesday and Saturday; use seven fictional daily
reading durations; write a 100-word reflection afterwards.
Hypothesis to test: starting a small project and checking tutorials when
stuck may suit me.
Still undecided: which charting tool to use.
```

### Reading notes.md

```markdown
# Reading notes (fictional example)

Two methods to compare for my charting practice:

- Tutorial first: follow a complete worked example before making my own chart.
  This may help when the tool is unfamiliar. I need a time limit so that watching
  does not consume the whole practice session.
- Project first: start with a question and a small dataset, then look up only
  what blocks the next step. This requires a small enough task and an easy way
  to record questions I cannot solve yet.

These are invented comparison notes, not claims from a study. My question is
which method will let me finish a simple chart in two 30-minute sessions.
```

### Practice record.md

```markdown
# Practice record (fictional example)

In a fictional earlier practice, I spent 25 minutes watching a tutorial and
5 minutes opening the tool. I did not finish a chart. I understood the menus
but could not explain what question the chart should answer.

In another fictional practice, I started with seven made-up reading durations
and drew a rough bar chart on paper in 10 minutes. I then got stuck choosing
software and stopped. The sketch made the question clearer: how did the
reading duration vary across those seven days?

Next time I want to choose the tool before the session, keep one concrete
question, and record a single obstacle rather than open several tutorials.
This is one fictional record, not proof that one learning method is better.
```

## 中文

### 学习计划.md

```markdown
# 学习计划（虚构示例）

目标：本周用虚构数据完成一张柱状图。
已确定：周三和周六各安排 30 分钟；使用七天虚构阅读时长；
完成后写 100 字复盘。
待验证：先做小项目、遇到问题再查教程，是否适合我？
尚未决定：使用哪个绘图工具。
```

### 阅读摘记.md

```markdown
# 阅读摘记（虚构示例）

比较两种绘图练习方法：

- 先看教程：完整跟做一个例子，再制作自己的图表。工具不熟悉时可能有帮助，
  但需要限制观看时间，避免占掉整次练习。
- 先做项目：从一个问题和小数据集开始，只查阻碍下一步的知识。
  前提是任务足够小，并且有地方记录暂时解决不了的问题。

这些是虚构的比较材料，不是研究结论。我想知道哪种安排能让我在两次
30 分钟练习内完成一张简单图表。
```

### 实践记录.md

```markdown
# 实践记录（虚构示例）

一次虚构练习中，我看了 25 分钟教程，用最后 5 分钟打开软件，没有完成图表。
我认识了菜单，但说不清图表要回答什么问题。

另一次虚构练习中，我拿七天编造的阅读时长，10 分钟画出了纸上柱状图，
随后卡在软件选择上而停止。草图让问题更清楚：这七天的阅读时长如何变化？

下次希望在练习前选好工具，只保留一个具体问题，并记下一项阻碍，
避免同时打开多个教程。这只是虚构记录，不能证明哪种学习方法更好。
```
