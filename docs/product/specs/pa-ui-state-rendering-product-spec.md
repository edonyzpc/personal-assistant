# PA UI State And Rendering Product Spec

Document status: Approved
Updated: 2026-10-20
Work item: B-181
Decision: [DEC-071](../decisions/dec-071-pa-ui-state-rendering.md)
Authority: 本 feature 的用户行为与验收标准；Approved 指 Owner 已确认的产品选择，当前实现契约与最终验证见文末。暂缓范围不视为已完成验收。

## Problem And Product Outcome

- User problem: 任务/正文刷新重建界面，导致展开项丢失、阅读跳动、输入或局部操作被打断。
- Product outcome: 数据变化局部呈现，用户操作有连续性；错误与生命周期清理限于所属视图。
- North Star fit: 安静且可信、低管理负担、渐进呈现；不给用户增加调度或状态管理设置。

## Scope

### In Scope

- B-181/REQ-01: 稳定身份和局部刷新，保留未变化实体的展开、选中、输入和有效 DOM 交互；覆盖 Chat 任务壳及后续 Pagelet 列表/详情。
- B-181/REQ-02: 变化正文发生选字、说明展开或控件交互后暂停替换，任务进度继续，用户以「查看最新」恢复正文。
- B-181/REQ-03: 短暂隐藏保留阅读与输入现场并关闭菜单；真正关闭、重开和重启恢复草稿及阅读位置，不抢焦点。
- B-181/REQ-04: 草稿/阅读设备本地白名单保存，隔离视图和会话，保存失败可见，损坏或迟到结果不覆盖有效新编辑。
- B-181/REQ-05: 减少无关渲染与排队，暂停隐藏显示工作，释放关闭资源；保留完整内容、原生 Markdown 及已有显示兼容。
- B-181/REQ-06: 桌面/iPhone/iPad 共用组件与逻辑，按容器宽度适配 PA 外观、触摸和键盘；Pagelet 动态行与阅读定位协调。
- B-181/REQ-07: 保持既有业务动作、来源与权限责任；一个视图或正文错误不重置其他视图，恢复不产生任务重发。

### Non-goals

- 不重写 Agent/任务服务，不改变历史、原文、发送、取消、Undo 和来源准入。
- 不引入通用 DOM diff、新 Markdown parser、Chat 历史虚拟化、内容裁剪、跨设备同步、通用持久化框架或大型组件套件。
- 不在一次迁移中重做全部 PA surface；其他界面后续触及时复用已形成的组件与约束。
- 不继续原型修补，不把设备连接或模拟结果算作真机通过。

## User Flow And States

| 场景 | 用户看到的行为 |
| --- | --- |
| 任务状态/无关实体刷新 | 对应信息更新；当前展开、输入和阅读不重置 |
| 变化正文内开始交互 | 当前正文保留；若有新正文，显示轻量「正文有更新 · 查看最新」；不遮挡原内容 |
| 点「查看最新」 | 显示最新有效正文并恢复后续更新；用户再次交互可再次暂停 |
| 切到笔记再回来 | 菜单已关闭，其余存活视图状态保留；无自动聚焦和弹窗 |
| 关闭/重开、应用重启 | 恢复未发送草稿、阅读目标及必要上下文；菜单/焦点/选区不恢复，所有展开项不批量持久化 |
| 找不到原阅读目标或附件来源 | 阅读退回同 surface 的合理邻近位置；附件保留可见失效提示，在重新核验前不能据此发送 |
| 保存失败或 UI 局部错误 | 本次输入继续可用，明确提示恢复能力受限；局部重试不重置其他视图，不自动重发业务动作 |

暂无内容沿用现有空态。窄容器允许控件换行和详情单栏，但相同动作与状态含义保持一致。

## Trust, Data And Authority

- Source evidence: 已确认选择见 DEC-071；实际桌面、阶段/差量检查和未验证项见最终验证记录。
- Data sent / stored: 不新增 provider 请求；设备本地只存恢复所需草稿、可复核引用和阅读快照，发送时仍走既有来源准入。不存令牌、DOM、函数、运行期授权或图片二进制。
- User disclosure / confirmation: 已确认的体验无需再次询问；恢复不获得新权限，保存失败和失效引用可见。
- Reversibility / recovery: 清空/发送成功消费草稿需更新保存状态，删除对应会话清除其记录并使迟到回调失效。恢复仅影响 UI，不重放业务效果。

## Acceptance Criteria

- B-181/AC-01: 同任务连续刷新以及另一任务刷新后，已展开 Details、当前编辑和选中实体保持；只有被删除/更换的实体释放自己的状态。
- B-181/AC-02: 正文内选字或操作说明控件后，旧正文节点保持且进度更新；新正文合并为最新一份，完成态也不强制替换；点「查看最新」才恢复。非该区域更新不受阻塞。
- B-181/AC-03: 切走返回保留阅读与输入且关闭菜单；全新 view/store 及应用重启可恢复草稿和语义阅读位置，恢复过程被真实新编辑/滚动优先打断，无焦点抢占。
- B-181/AC-04: 不同设备、会话和并存视图不互相覆盖；读写失败、损坏记录、清空及晚到保存/发送失败恢复不会复活旧草稿；没有任务 tick 写盘。
- B-181/AC-05: 同文/无关刷新不增加原生构建；每区域待处理工作有界，隐藏不发布，关闭后无迟到 DOM 发布和资源残留；表格、链接、媒体、Mermaid 与完整历史契约保持。
- B-181/AC-06: 宽/窄实际容器可读可操作，无横向挤出和动态行重叠；Pagelet 选择和阅读锚点在更新后合理保持。主要触摸动作至少 44px，移动输入至少 16px；键盘焦点、展开语义和 reduced-motion 得到保留。
- B-181/AC-07: 真实动作仍调用原服务并沿用既有准入；关闭/暂停显示不取消后台任务；一个 root 或 Markdown 区域错误不会清空其他草稿、串写状态或触发重复效果。
