# PA Chat Image Generation Product Spec

Document status: Approved
Updated: 2026-09-18
Work item: B-133
Decision: [DEC-038](../decisions/dec-038-chat-image-generation.md)
Authority: Owner 已确认的 Chat 图片生成与编辑行为、数据边界和验收要求。Approved 指产品范围已确认；当前实施与验证状态见 Tracker，不表示功能已验收或获得 Git/发布授权。

## Problem And Product Outcome

用户在 Chat 讨论或写作时可以就地生成、比较与修改视觉素材，完整保留可用结果，
减少切换外部工具、下载再导入的摩擦。图片创作按需触发，不变成主动配图推送或图库管理负担。

## Scope

### In Scope

- B-133/REQ-01 — `@CreateImage` 显式入口与明确自然语言均可生成图片。主 Agent
  区分生成请求、看图、写 prompt、讨论建议与不明确意图；歧义时澄清。
- B-133/REQ-02 — 首版使用 Wan 图片服务，支持文字生成、图片参考创作和文字编辑。
  用户可主动上传、粘贴、从 vault 选择图片；不自动搜集图库。
- B-133/REQ-03 — 连续编辑绑定确切图片，保留输入与所有输出版本。可从任意已有
  结果分支修改；多候选无法确定时询问，不默认误选。
- B-133/REQ-04 — 聊天内逐张展示结果，可放大、复制图片内容、下载原始结果文件、
  选择该图继续修改。复制链接或保存到 vault 不能替代复制图片与下载到设备。
- B-133/REQ-05 — 图片连接可独立配置或复用兼容聊天连接，Chat 与 Featured Image
  共用该连接。独立图片连接不随聊天服务商切换而失效；连接选择、不可用原因可见。
- B-133/REQ-06 — 迁移保留 Featured Image 既有模型、数量、路径及笔记插入语义；
  Chat 参数不覆盖其默认值，改变统一连接的影响清楚可见。
- B-133/REQ-07 — 默认一张；用户明确要求可多张。Agent 不自行多次付费试图择优，
  超出接口范围时说明并协商，不静默少给或自动扩成多批。部分成功保留成功结果。
- B-133/REQ-08 — 生图期间可继续文字聊天、切换会话；结果回到原会话原卡片，
  不抢焦点。提交后的请求固定，后续消息不会暗改在途任务。
- B-133/REQ-09 — 展示真实提交、生成、保存与异常状态，支持停止；区分本地停止
  与远端确认取消，不保证点击停止就没有费用，也不把已提交视为已生成。
- B-133/REQ-10 — 重启后有可核实任务身份时恢复查询或结果保存；提交后无身份/受理未知
  时保留不确定状态，不自动重新提交。可证明从未发送的请求显示未提交，允许继续。
  主动停止不自动恢复；过期和连接缺失可解释。
- B-133/REQ-11 — 生成结果原文件进入现有聊天图片管理，聊天引用稳定资产；
  不依赖临时 URL。聊天保留期间记录 AI 生成来源、实际模型/描述/参数和输入版本关系；
  删除对应聊天内容后不再保留这些生成元数据。
- B-133/REQ-12 — 延续原件保留、独立清理、同步状态说明和显式保存到笔记的迁移
  机制；每次保存均由用户选择目标笔记，迁移为正式附件并插入图片引用。删除聊天
  不自动删除原文件，但清除对应任务、版本、提示词及来源引用；普通附件与已保存
  笔记不被任务清理误删。
- B-133/REQ-13 — 每次物理生成/编辑发送遵守实际授权来源与费用范围；首次透明
  说明图片服务会接收相关文字/图片、可能使用 API 额度及结果存储。已明确请求后
  不增加重复确认；不以创作图片/画面内容自动形成用户事实或长期偏好。
- B-133/REQ-14 — 按变化与风险取得入口、文件导出、复制、停止和恢复的充分证据。
  默认 Obsidian Desktop + CLI mobile simulator；只有移动端强相关依赖或具体平台
  风险才追加对应真机案例。平台限制如实呈现，不静默降级成链接复制，不把模拟器
  或静态测试冒充真机验证，不重复测试未变化的跨平台通用行为。

### Non-goals

- NG-01: 首版 OpenAI 或其他图片 provider、公共图床/托管上传、任意 URL 抓图工具。
- NG-02: 局部涂抹/框选编辑器、图层、独立图库、自动择优生成与隐藏批处理队列。
- NG-03: 跨设备聊天/任务同步、应用关闭后的本地常驻执行器。
- NG-04: 放宽 B-129 静态媒体与原件边界；动画/外部资源 SVG 仍由 B-132 承接。
- NG-05: 主动给笔记自动配图、扫描整个图库、用生成结果自动更新个人画像。
- NG-06: 将 Chat 重启恢复延伸为 Featured Image 重启后自动插入笔记。

## User Flow And States

### Create / Reference / Edit

输入 `@` 选择 CreateImage 后输入描述，或直接给出明确自然语言请求；添加图片本身
不构成生图指令。选择“修改这张”时输入区展示目标图片，可移除或更换。用户描述
完整时直接执行；仅入口标记、缺少必要描述或编辑目标时请求补充。

生成卡片逐步显示真实状态。每个输出图保持独立操作入口；失败项单独说明，已成功项
仍可使用。后续编辑生成新结果；“重新生成”与“编辑指定图片”保留不同的输入语义。
生成结果尚未可用时，Agent 不声称已看见或可以准确描述其内容。

### Background / Stop / Recovery

任务归属确定的会话和消息。新聊天轮可并行进行文字交流；旧图片完成事件不覆盖
当前回复、草稿或其他会话。用户停止后显示实际停止范围；清除/删除会话同时停止
该会话的本地任务交付，保留已有原文件，不因迟到回调重建被删除的聊天。

重开后查询原任务并恢复保存，不重做需求理解或重放生成。连接身份不匹配、凭据
缺失、结果过期、文件缺失分别提示。未知结果不以“失败后自动重试”掩盖收费不确定性。

## Trust, Data And Authority

- 来源为当次请求、确切授权图片及既有规则准入的相关上下文；不默认全量发送当前
  笔记、历史图片或 Memory。主 Agent 与图片 provider 不同时，披露实际接收方。
- 用户原文件不变；发往 provider 的图片副本继续处理源敏感元数据，同时避免用
  缩略图或白底 JPEG 无谓损失编辑信息。若输入含透明像素且 Wan 不接受，先暂停
  并说明；用户确认后才为本次任务制作无透明像素的白底 PNG 副本并继续提交。
  用户可停止该暂停任务；未确认或停止均不得提交该图。输出原文件与系统剪贴板格式转换分开。
- AI 生成标识与事实来源分离；生成、下载或普通改图不构成长期风格授权。
- 任务及聊天元数据按本设备存储规则处理；凭据使用 SecretStorage，不进入任务、
  聊天内容、图片详情或日志。临时远程链接不是持久图片引用。
- 同步排除按实际可证明状态说明；不承诺仅因目录名就排除同步。
- 本功能权限限于授权生图和所需图片资产，不给予 Agent 任意 vault 写入权限。

| B-133/AC-04 | 每张图可放大；复制后粘贴得到图片；下载到设备得到正确原文件，且多图操作不串图 |

| B-133/AC-09 | 提交/完成/保存阶段与服务证据一致；停止和完成竞争可解释，停止不被错误宣称远端取消 |
| B-133/AC-10 | 重启覆盖尚未提交、有任务 ID、保存中、受理未知、已停止、过期和连接变化；自动恢复不新增生成请求，未提交可明确继续 |
| B-133/AC-11 | 重开历史可使用本地结果；临时 URL 失效不影响已保存图片；详情保留正确 AI 来源和输入版本 |

| B-133/AC-13 | 首次说明与实际外发一致；来源失效/撤回后不新发对应素材；日志无密钥/原图载荷，不虚构用户事实 |
| B-133/AC-14 | Desktop 实际入口、复制/下载与生命周期通过；CLI mobile simulator 覆盖受影响布局/可达性/适用交互；仅已识别的移动强相关依赖/风险完成最小真机案例，或明确保留未过的必要证据；Featured Image 回归通过 |

## Delivery Constraints

按 Owner 2026-09-18 的补充要求，遵循 DEC-038 的精简设计与验证约束：保持已确认
功能和质量目标，采用最小合理实现与最低充分证据。架构不为假想扩展提前通用化，
测试不为覆盖率数字、组合数量或已有通过结果另造工作。默认验证顺序为 focused
source → Obsidian Desktop（CLI 准备状态、真实操作验证）→ CLI mobile simulator；
仅具体平台依赖/风险触发真机补测。必要共享 gate 仍按 AGENTS 执行并复用结果。

[讨论细节验收映射](../../development/active/chat-image-generation/sdd.md#13-discussion-detail-traceability)
补充逐项场景与负例，供后续核对；它不新增重复测试门或第二份进度表。
