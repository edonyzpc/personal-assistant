## Problem And Product Outcome

设置总览回答“现在用什么、哪里需要处理”；AI 详情回答“哪个功能用哪个连接”；
连接编辑回答“这个连接怎样配置”。普通用户配置一项默认即可使用，多服务用户
也能直接找到例外和模型，不需要反复切换管理模式。

目标是“安静且可信”：减少常驻说明与重复控制，准确显示已保存事实，保留有效选择。

它是可交互示意，不是完整字段清单；示例名称、模型、地址、模拟保存／Memory、

## Scope

- B-195/REQ-01: 总览保留四组、简短真实摘要和折叠偏好；移除可见快速跳转、移动进度及宽屏悬停目录，保留现有外部精确跳转能力。
- B-195/REQ-02: AI 总览通过统一 Open 进入内部详情；默认连接、独立用途、已保存连接各有清楚层级，不再在总览内切换整套管理／编辑界面。真正首配、已有连接但无默认、旧配置待迁移分别使用符合事实的主操作。
- B-195/REQ-03: 既有连接可直接编辑常用模型；有预设服务保持简单首配，Custom 直接展示 PA 已接入用途的地址／模型，完整高级控制可达。用途可留空保存，但未完整状态如实显示；已有地址仍只读，修复通过新建连接及显式替换用途，不复制 Key。用途选择与连接资产修改各自有明确保存含义。
- B-195/REQ-04: 改变选择后预览实际受影响用途，显式“应用用途选择”／取消；继承、独立、未配置三种语义保留，独立项即使等于默认也不丢失其独立性。真正执行提交时核对与预览相关的基线，若变化则本次零写入并重新预览，由用户再次明确应用。提交中的选择状态跨返回／重入保留，对应选择区防止重复提交及相互覆盖，导航仍可用。
- B-195/REQ-05: 凭据状态使用 present/missing/unknown 的已知事实；Key 留空不清除旧值，移除／删除沿现有明确操作，不新增被动读取或联网验证。
- B-195/REQ-06: Memory 摘要、切换影响与操作沿当前领域事实；切换不自动付费准备、不删旧份，切回兼容份可复用。普通界面使用笔记检索／Memory 等产品语言。
- B-195/REQ-07: 返回与局部刷新保留展开、滚动和非秘密草稿，连接行轻量提示“有未保存修改／继续编辑”；取消不提交、离开编辑清空 Key 草稿。Settings 关闭及迟到保存不复活页面或夺取焦点；明确提交后的成功／失败按真实结果恢复状态，离开不代表撤销。
- B-195/REQ-08: 完整保留当前 provider、模型／地址、Policy、服务选项、迁移、删除引用／任务处理以及非 AI 有效设置；共享配置 owner、Chat 首配和现场入口保持。
- B-195/REQ-09: 统一细线披露／进入／返回图标，沿宿主主题和原生语义；选择器仅选择值，不在 change 时触发页面导航，相邻独立“添加连接”文字按钮表达带用途的新增动作。zh/en、桌面／移动、窄屏、长值、200% 文本与键盘触摸均可完成主要路径。

## Non-goals

- 不新增服务商、模型目录、自动探测／测试、连接向导、搜索、额外侧栏或全局导航 store。
- 不改变现有模型默认、协议、持久化格式、权限、来源、学习和后台策略；不清理历史数据。
- 不将示意的非 AI 占位页当作重写或删除功能的授权，不复制 Memory 管理／维护编辑器。
- 不重做宿主设置外壳，不引入自定义品牌主题；实施授权包含本地 test vault 验证，不包含提交、推送或发布。

## User Flow And States

| 用户任务 | 目标路径 | 必须可辨认的状态 |
| --- | --- | --- |
| 查看当前 AI | 总览 → AI 摘要 | 已保存默认、独立例外、相关配置问题 |
| 改默认或独立用途 | Open → 默认／按功能配置 → 影响 → 应用用途选择 | 草稿与已生效分开；提交时基线变化则零写并重新预览；在途选择区保持保存中，取消不能撤销已提交事务 |
| 改模型或 Key | AI 详情中编辑连接 → 保存 | 编辑的是哪条连接、哪些用途受影响、保存是否成功；返回保留的非秘密编辑在连接行可发现 |
| 添加连接 | AI 详情列表“添加连接”；或默认／用途选择器旁的独立添加按钮 | 前者保存资产，后者保存并用于明确对象；选择器移动选项不跳页，按钮通过点击或 Enter／Space 激活，返回恢复该触发项 |
| 配置 Custom | 选择 Custom → 直接填写支持用途的地址／模型 → 保存 | 不把缺省为空的字段称作有预设的可选调整；允许用途留空，显示相应用途暂不可用；地址修复走新连接及明确替换 |
| 查看 Memory | AI 中当前笔记检索摘要 → 既有管理／维护入口 | 关闭、检查中、可用、待更新、待准备、失败有真实区分 |
| 返回或离开 | 编辑 → AI 详情 → 总览 | 返回保留非秘密草稿；显式取消丢弃；Key 草稿不随页面保留；用途应用在途时返回／重入仍展示同一次保存，成功或失败后恢复选择区 |

| AI 状态 | 主操作 | 不能混淆的边界 |
| --- | --- | --- |
| 真正首次配置 | 添加默认连接 | 保存并设为默认，沿现有首次初始化语义；不导向只保存资产后仍无默认的路径 |
| 已有连接但无默认 | 选择现有默认，或添加并设为默认 | 全部用途可以独立工作，不把无默认一概标成不可用，不自动更改独立用途 |
| 旧配置待迁移 | 进入既有迁移／补全操作 | 不冒充新用户，不丢旧连接事实、凭据关联或 Memory |

完整页序、状态转移、字段归位及错误处理由 SDD 具体说明。

## Trust, Data And Authority

UI 不读取原始 Key 做摘要，也不以“已配置”声称认证成功。缺失和未知是不同状态；
缺一项能力不把整个 AI 设置标成未完成，不自动选择其它连接兜底。

所有写入沿 `PluginAIConfiguration`；Memory 沿 MemoryManager/VSS 当前 owner。
独立笔记检索连接只影响准备／检索，文字提取和对话仍使用聊天连接。
切换不获得新的外发、付费或删除许可。准备／更新与删除／移除保留现有告知及恢复。

## Acceptance Criteria

- B-195/AC-01: 首次只展开 AI，重开尊重折叠偏好；宽窄布局均无快速跳转／进度／悬停目录，原精确跳转仍定位正确。
- B-195/AC-02: 总览 → AI 详情 → 连接编辑完整可达；总览只有一个 AI 详情入口，标题不重复堆叠，独立例外收起后仍可见。分别验证真正首配、已有连接无默认、旧配置待迁移的主操作，无默认但全部独立时不误报整体不可用。
- B-195/AC-03: 已有连接从 AI 详情直接进入常用模型；有预设服务新建无强制高级步骤，Custom 地址／模型直接可见；留空用途保存后准确显示未完整，已有只读地址可通过新连接与显式用途替换修复且不复制 Key。连接保存不偷偷提交其他用途草稿，取消用途选择不撤销已明确保存的连接修改。
- B-195/AC-04: 覆盖全部继承、部分独立、全部独立、独立恰等于默认、未配置和恢复默认；全部独立时改默认不假报三用途变化，无改动不生成冗长影响区。在应用点击后、实际执行写入前相关基线发生变化时，本次不写任何选择，刷新影响后才可再次应用；无关字段变化不被误判为冲突。
- B-195/AC-05: present/missing/unknown 分开表达；留空、替换、移除、保存失败及删除被引用连接符合现有边界；普通渲染无秘密读取或网络探测。
- B-195/AC-06: 改聊天模型不声称笔记检索数据变化；A→B→A 保留可复用 Memory；改名／换 Key 不另建，Memory 关闭时无准备／更新按钮；检查与恢复失败不假报可用。
- B-195/AC-07: 返回、取消、局部刷新、保存中离开、关闭后完成均保持正确草稿／焦点／效果归属；改模型后返回，连接行仍有未保存提示，应用用途选择不提交该模型草稿。延迟用途提交期间返回／重入仍显示保存中且不能重复提交或覆盖，导航可用，成功／失败后正确恢复；非 AI 草稿和现有 Memory／恢复深链接不受损。
- B-195/AC-08: 对照当前字段清单，所有有效选项和管理操作仍可达；Custom 图片准确说明 PA 当前未接入，未支持不等于服务商本身无能力；Chat 首配与历史兼容路径未收窄。
- B-195/AC-09: 外层分组与内层 disclosure 的图标、方向、对齐一致；进入／返回区别清楚。选择器用方向键改变值不跳页；相邻添加按钮可用 Enter／Space 激活，新增取消／返回恢复触发项及原选择草稿。zh/en、深浅主题、320 CSS px、200% 文本、长名称／模型和键盘触摸完成主要路径。
