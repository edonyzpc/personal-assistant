## Problem And Product Outcome

用户明确要求执行时，过时的确认、数量上限和控件要求会阻断任务；旧合同还会使开发
重新引入已撤销约束。目标是按当前授权完成任务、如实报告效果，让后台活动保持安静可控。
以[北极星](../pa-product-north-star.md)和本次明确选择为依据，不增加管理步骤。

### Non-goals

- 整体移除 Host、重新划分所有模块、增加通用授权分类器或第二规划/语言评审模型。
- 新增 Writing 自然语言自动入口、Ghost 自动首发、源范围自动放宽、B-119 AI 增强或
  独立 Weekly Review；不启用更宽的 B-112 Trust/Maintenance proposal。
- 新持久审计、备份目录、跨重载/跨设备 Undo、预算设置页、额度遥测平台。
- 改变 SnapDOM、来源资源网络权限、既定内容/媒体支持；删除所有内部算法参数。
- 本次方案阶段不实施 runtime、部署、模型调用、Git 或发布；实施授权独立记录于 Tracker。

## User Flow And States

明确修改请求 → Agent 选定真实目标并准备操作 → 同一请求内执行 → 展示完成/部分/失败/
未知及可用撤销。用户要求仅预览时可停在未执行差异；主动确认该预览是新的执行请求，
不让旧待处理状态自行启动。未知效果先查询原操作，不能用无输出或超时证明未执行。

明确笔记配图 → Agent 找到笔记 → 来源域绑定真实文件快照 → 现有专用描述提炼 →
现有图片服务生成/交付。无控件选择不再成为阻断条件；模糊同名、冲突选择需要澄清。

自动发现沿既有开关、来源权限和预算执行；手动入口使用相同领域能力但不占自动额度。
长 Share Card 沿既定渲染/分页/导出，内容不静默截断。桌面及移动共用权限/效果语义。

## Trust, Data And Authority

Agent 对用户语义负责；来源域对允许材料与派生关系负责；领域 owner 对文件、版本、
并发基线和副作用负责。明确请求可授权执行，但模型输出不能伪造文件/权限/执行回执。
对已接受范围的费用不重复确认；发现实际超范围时由 Agent 解释具体差异，不编造价格，
也不引入每次任务前的价格查询或审批流程。必要的首次外发告知沿原合同保留。

不修改笔记外的隐私或发布边界。撤销仅覆盖真实已完成且仍可撤销的效果，不能覆盖
用户后续编辑。图片联合删除保留共享引用保护和写前可恢复快照。

## Acceptance Criteria

| AC | 必须证明的用户结果 |
| --- | --- |
| B-161/AC-01 | 清楚的多来源请求无篇数确认；真正歧义或超授权/费用范围才问；取消后不启动未发生的效果；无语义正则或新增固定阈值 |
| B-161/AC-02 | 明确修改通过真实入口直接完成；分析、引用指令、仅预览均不写；并发编辑不被覆盖；部分/unknown 不假成功不重放，撤销不破坏后续编辑 |
| B-161/AC-03 | 无来源控件的唯一笔记指代可生成，绑定正确笔记；同名歧义可问；换页不偷换来源；排除/撤权及已选控件冲突不越界；一次请求无重复付费提交 |
| B-161/AC-04 | 普通 Chat 文字写作不自动建作品；显式 Writing/继续作品正常，仍可只讨论；父版本身份正确 |
| B-161/AC-05 | 准备请求不正式发布；过期版本确认不能更新新版本；unknown 查询原操作不建重复草稿；新文章仍由用户首发 |
| B-161/AC-06 | notes/web/combined 三范围均守读取与派生输入边界；排除和撤权继续生效，不能用直接执行或自然语言选源绕过 |
| B-161/AC-07 | 代表性内容超过 50K 且超过 24 页仍完整到末尾；顺序及受支持媒体保持；预览/Copy/Save 同批内容一致；取消停止后续工作，真实资源失败可理解且不假称完整 |
| B-161/AC-08 | 自动池耗尽时手动入口仍可执行且不改自动计数；本地 Maintenance/Graph 达旧前台额度也能启动，不附带启用 AI 增强 |
| B-161/AC-09 | 自动任务默认 12/36；启动计一次，缓存命中/准入拒绝不计；reload 不清空消费；存储失败不放开自动任务；手动不因自动计数存储故障被阻断 |
| B-161/AC-10 | 证明当前入口仍走统一发现；旧管线无复活；合法残留消费者的语言设置/结构校验/10-50预算保持，语言正则不再产生拒绝或调用；候选默认可内部调整 |
| B-161/AC-11 | Agent 能按需要重复读取且不被同参复用强制返回旧值；不会凭 latest/当前等词选择策略；超过旧任意 Operations 限额仍可完成或报告实际资源失败；完整事实不截断，撤权/原子写/可恢复删除不退化 |
| B-161/AC-12 | 讨论每项均映射任务/证据；旧合同明确 successor 与适用范围；八类文档接续问题逐项处理；不把新目标写成已验证实现，不篡改 F-24 等旧证据 |

## Open Decisions

本范围无未决产品选择。具体实现方案由 SDD 给出；整体 Host 去留及其他非目标不阻挡本包，
也不能由实施者自行决定。新的实质偏差另行提交，不能借局部实现改变上述选择。
