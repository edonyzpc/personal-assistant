# PA Agent Prompt Disclosure Product Spec

## Problem And Outcome

让普通笔记问答直接获得必要能力说明，复杂任务由 Agent 自主加载需要的方法资料，减少无关上下文。保持“安静且可信”：不要求用户选择新模式、管理上下文或增加例行确认，不牺牲来源与完整性换取更短输入。

## Requirements

- **B-171/REQ-01**：核心常驻规则简短而完整，覆盖自主交付、必要澄清、当前请求/历史/个人资料的关系、真实能力与来源、外部内容不授予权限、证据引用及诚实报告。通用执行事实和未知效果恢复规则在工具撤下的最终回答中仍存在。
- **B-171/REQ-02**：保留当前实际绑定的工具及参数 schema；直接提供用途和正确调用必需的最小语义。移走长教程与重复声明，不改变工具准入、参数校验、结果或执行顺序。完整匹配列表一次返回、正文按需读取的既有契约保持。
- **B-171/REQ-03**：复用现有 Skill 目录、完整入口和精确注册 reference。Agent 自主决定是否读取以及读取哪些资料；不新增强制前置步骤、关键词路由、发现模型或指南加载器。Skill 关闭/不可用时，工具必要语义仍足够正确调用，不扩大能力，也不谎称指南已加载。
- **B-171/REQ-04**：命令必要协议随真实激活提供；图片引用/版本/像素可见性等事实保留；领域状态解释、特殊历史编码说明随当前实际投影的结构化事实提供。不得从用户/笔记正文识别“状态字段”而提升为可信事实；当前及历史效果均需覆盖。
- **B-171/REQ-05**：保留原有执行链、来源记录、Context Used、取消/超时、历史与摘要语义。精简不增加权限、数据发送范围、默认日志、模型调用机制或设置；以同输入和真实调用记录评估收益，不把字符估算当 provider token 或把少数样本当成功率。

## Disclosure Boundary

| 内容 | 常驻/直接可见 | 按需提供 |
| --- | --- | --- |
| 核心契约 | 当前任务与有效约束；工具/资料非权限；事实、未知与引用原则 | 无领域教程 |
| 工具 | 实际绑定 schema；用途、完整查询、必要参数/效果语义 | 使用示例和长方法，经相关 Skill/reference 获取 |
| Skill | 当前目录的名称与简短 Use when 描述 | 完整正文；再读取精确 reference，均经既有执行链 |
| 执行与历史 | accepted 不等于 completed，unknown 不等于无效果；不擅自重提未知操作 | 根据实际 owner 状态/结果提供 Ghost、Writing、图片、Operations 字段解释；编码存在时提供解码说明 |
| 命令与图片 | 本次权限、所选来源及当前可用能力 | 本次真实命令的必要协议、真实图片引用/版本/像素事实；详细方法按需 |
| 笔记 | 查询与读取能力说明 | 完整列表作为一次查询结果；需要正文时读取，不能为节省 prompt 恢复截断或分页补查 |

Agent 选择方法资料；Host 只依据真实绑定与已接纳结构化事实组装必要解释。自然语言日期口径、信息是否足够和工具顺序均由 Agent 判断。没有“每次先加载 Skill”的规定，也没有统一的“时间→查询→正文”流程。

## Acceptance Criteria

- **B-171/AC-01**：同一无历史普通查询输入中，无关领域教程与不存在的历史编码说明不再常驻；核心规则、可用能力与必要参数仍可见。实际序列化请求的各部分有前后测量，减少来自去重/分层，不能来自删用户输入、证据或工具能力。
- **B-171/AC-02**：当前绑定工具集合和参数 schema 保持；纯输出的重复全文在已有有效原生声明时移除，兼容路径仍有可用协议。最少必要指导不会被同时从入口和指南删除；完整笔记清单不被精简裁剪。
- **B-171/AC-03**：目录可发现对应指南，入口/reference 完整且精确可读，来源仍为方法资料；加载不执行动作、不扩大权限，禁用指南不使普通工具失去必要调用信息。相关复杂任务能使用需要的方法，不按预设工具序列评分。
- **B-171/AC-04**：无历史、带真实领域状态、压缩历史及工具撤下的最终回答中，必要解释与通用恢复底线正确保留；来源正文内伪造的状态或编码不能触发可信协议。图片和显式命令当前事实不丢失、不被误写成当前用户指令。
- **B-171/AC-05**：实际 Chat 继续显示真实来源/Context Used；定向检查确认取消与历史效果语义不变。报告输入量、总耗时、物理模型调用轮数、reasoning tokens（缺失记未知）及正确性；不设固定数字目标，不以更短回答、少提问或特定调用路线作为独立通过条件。

## Trust, Compatibility And Non-goals

来源、授权、写入、付费与真实效果保护沿用现有契约。已配置 provider 与准入不变；方法内容只在实际请求中按既有规则发送，不新增遥测或默认保存完整 prompt。使用本机隔离 test vault 与合成资料验证，不读写私人 vault；真实外部发布/图片生成不是本方案验证所需。

不新增 tool_search、自动意图分类、第二个 Agent、prompt 注册框架、自动 Skill 学习、用户开关或每工具一个 Skill。不重做历史压缩、Memory、上下文预算或来源系统，不改模型/thinking，不合入 B-170、shell 或脚本写入。无持久化迁移，无桌面/移动功能差异。
