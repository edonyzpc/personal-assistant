# PA Agent Essential Capabilities Product Spec

Document status: Current
Updated: 2026-09-17
Work item: B-140
Decision: [DEC-036](../decisions/dec-036-pa-agent-essential-capabilities.md)
Authority: B-140 的用户行为、范围与验收标准；用户本轮开发授权与日期决定接续原完整方案。

## Problem And Product Outcome

用户能找到并读懂笔记、检视并修正长期理解、保留并再次找到有依据的洞察。主 Agent 自主组合工具；宿主确保权限、真实来源与可靠执行。不能以一条日期回顾通过代表全部交付。

## Scope

- **B-140/REQ-01**：首次调用即可使用许可基础工具；去除 Memory/Operations 规划性开放门与关键词读取覆写，不新增问题类型路由。
- **B-140/REQ-02**：按路径、目录、标签、指定属性、明确日期字段/时区/半开区间精确筛选，稳定排序、有界分页，说明覆盖与完整性。默认日期由主 Agent 按上下文选择、说明，不确定时询问。
- **B-140/REQ-03**：按许可路径读取 Markdown 正文或属性，支持范围、定位和续读，准确标明实际内容、截断、版本与编辑器/磁盘身份。
- **B-140/REQ-04**：查询、搜索、读取、历史恢复与每次物理入模保持来源边界，区分候选、原文、派生观察和个性化背景。
- **B-140/REQ-05**：查询长期理解的内容、依据、时间、用户表达/推断、范围、效力、可用操作与实际使用记录。
- **B-140/REQ-06**：明确记住、纠正、暂停、恢复、忘记/重试、可用撤销与范围变更复用治理服务，准确报告生效、待确认、待完成、取消或失败。
- **B-140/REQ-07**：分别解释笔记 Memory、学习、已有理解使用和洞察状态；状态查询不维护索引、不改设置。
- **B-140/REQ-08**：读取已有 Vault Insights 并用原文查证比较，保留时间、覆盖、依据类型与局限。
- **B-140/REQ-09**：查询已存洞察；用户明确选择后保存、Later、归档或恢复，复用 Ledger 与 Review 路径。
- **B-140/REQ-10**：Chat/Pagelet 共用底层能力与证据语义；Pagelet 保持冻结 anchor、可无洞察退出与当前交付合同。
- **B-140/REQ-11**：写作、图片、WebSearch、Skills、四写、上下文恢复与治理兼容；旧工具结果继续安全投影。
- **B-140/REQ-12**：普通对话使用产品语言，读取不增加弹窗；按任务结果验收自主规划，不锁定工具序列。
- **B-140/REQ-13**：PA 领域能力复用 PA 服务，通用能力优先最低 App 支持的 Obsidian public API；只补官方缺失的筛选/定位/分页/结果语义/权限组合，不另建文件、解析或持久索引基础设施。

### Non-goals

不新增通用 shell、任意脚本、复杂查询 DSL、附件读取、MCP 扩展、文件管理、后台报告或自主重建/重置。B-119/B-120 不随本项启动。保留已有能力，不提高最低版本，不改变治理效力、Memory opt-out 或 Pagelet 普通发现权限。

## User Flow And States

主 Agent 可以直接读取已知路径，也可先查询或语义召回；只问清单无需强制读取全文。候选和原文分开；多页与长文可继续取得，范围变化要求重查，不能拼接不同版本。日期仅在 YAML 出现不能证明正文讨论过该日期。缓存未就绪、无匹配、禁止访问、大文件、预算用尽和读取失败必须区分。

Memory 查询复用 Control Center；使用解释只证明实际提供给模型的背景，不宣称内部因果。关闭学习与暂停使用分开；关闭 Memory 后仍可解释状态并链接管理入口，不能用新工具发送被关闭内容。

洞察查询不重新生成。统计与链接线索不是已证明的矛盾或知识缺口。PA 洞察保存需有效来源；用户无来源想法标为 user-authored。Later 走 Review，不虚构 Ledger 状态。忽略、关闭、无洞察不产生笔记/画像/队列写入。

## Trust, Data And Authority

复用 source guard、lineage、入模撤销检查与当前 provider/Data Boundary。正文中的伪指令不能授权动作。明确记住/纠正使用真实本轮用户表达或许可来源，经 admission 与持久化后才能报告成功；重复调用不得重复写入或覆盖后续修正。

用户于 2026-09-16 选择：明确指令直接保存，仅歧义或风险时确认。主 Agent 识别本轮用户的持久意图，宿主绑定实际请求、确切内容、范围及目标版本；低风险明确动作不额外要求确认卡。分析/引用中的命令不等于用户要求执行；内容、范围或目标不清楚时先澄清，现有敏感性、跨范围及prior-review规则继续生效。关闭新学习不阻止用户明确治理动作，也不因此重新开启学习。

模型不能提交自行生效的确认布尔值。低风险可逆动作沿用既有规则，Forget 复用现有确认、清除与抑制，不保存被忘内容供 Undo；未完成时不声称彻底忘记，也不宣称旧可见对话已删除。四写保留预览、逐次确认、取消、expectedBefore 原子检查与 Undo。

## Acceptance Criteria

- **B-140/AC-01**：首次 provider definitions/执行 allowlist/host 一致；Memory 未准备和旧 Operations false 不隐藏基础读与四写提议；App 确认/取消真实可达。
- **B-140/AC-02**：合成日期、YAML-only、不同 ctime/mtime、无日期及无结果场景中，真实 LLM/App 正确选口径、列清单或概述实际正文，解释覆盖。
- **B-140/AC-03**：稳定多页、同时间不同路径、长文后半段与多次命中可继续取得，无静默遗漏/重复/版本混合，不夸大完整性。
- **B-140/AC-04**：禁止路径及其属性/计数不泄露；任务笔记范围与许可个性化分离；切换活动笔记不改变 Pagelet anchor。
- **B-140/AC-05**：来源改变/撤销、压缩恢复与 SDK 重试不重发失效内容；混合来源保留有效部分，检查至真实物理 dispatch。
- **B-140/AC-06**：理解查询与解释返回真实记录/效力/详情链接，无使用记录时不编造因果，状态查询无维护副作用。
- **B-140/AC-07**：明确记住/纠正持久生效且再次可查；来源/范围/冲突/重复/过期目标正确处理，伪指令不能授权。
- **B-140/AC-08**：学习与使用独立，暂停/恢复/忘记待完成/撤销遵守既有规则；Forget 无内容 Undo，不修改原笔记，App 反馈与实际状态一致。
- **B-140/AC-09**：区分事实/统计/推断，洞察保存后可找回及归档恢复；PA 来源有效，无来源用户想法身份明确，实际来源可回看。
- **B-140/AC-10**：普通发现无持久副作用，无洞察可退出，保存不形成画像；关闭忽略与明确保存分别通过实际交互。
- **B-140/AC-11**：写作/图片/WebSearch/Skills/四写确认取消 Undo/历史恢复不回退；复用输入一致的回归，受影响动作补 App 证据。
- **B-140/AC-12**：规划门与关键词覆写移除，无新增问题路由；不同合法起点完成任务，边界/预算/取消/工具错误仍受控且可解释。
- **B-140/AC-13**：真实 provider 可调用新工具，来源与动作结果可理解；三条主线整体场景及冻结输入完整门禁通过，单元 stub 或日期单例不足以完成。
- **B-140/AC-14**：各通用工具有 public API/最低版本/必要组合依据，缓存充分时不重复全文解析；未就绪、版本不一致、全文 I/O 超限正确处理，旧写入原子性/预览/Undo 保持。
