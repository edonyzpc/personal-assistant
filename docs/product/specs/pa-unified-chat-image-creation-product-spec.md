## Problem And Product Outcome

用户通过一个 CreateImage 动作，根据画面描述、整篇笔记或选中文字生成图片。
实际图片描述与来源相符，保留 Featured 的内容提炼/画面构思能力，不要求用户理解内部
模型步骤。主动配图服务于笔记发布/复用，不主动生成或推送。

## Scope

### In Scope

- B-152/REQ-01 — 统一入口。保留 `@CreateImage`，不增加 `@FeaturedImage`。来源为
  不附加笔记/当前全文/选中文字；有选区默认选区，普通入口无选区默认不附加笔记。
  来源可预览、切换、移除；选择动作不执行，发送才执行。来源非空时补充文字可留空，
  没有内容和描述时不可发送。未选来源控件时，明确自然语言笔记指代也可由 Agent
  查找并绑定实际文件，不要求先点击控件。
- B-152/REQ-02 — 确切来源。绑定笔记身份和内容快照，发送后切换笔记、选区或下一轮
  范围不改变在途输入；选区不扩大到附近段落/全文。真实同名歧义或控件与文字冲突先
  澄清，不静默覆盖已有选择。无效来源、文字与范围冲突、内容
  超限不能静默换源或截断后声称用了全文。继续服从 Data Boundary 和本轮来源权限。
- B-152/REQ-03 — 专用提炼。全文/选区沿用现有 Featured 提示词基线，保留主题/情绪、
  主体/场景/风格/镜头/氛围/细节、词典与示例；首版保留独立文字模型调用，输入为所选
  内容与本轮要求，不混入无关历史/Memory。失败、空输出或超限时说明失败，不改发原问题。
  普通完整画面描述不强制走该专用调用。
- B-152/REQ-04 — 唯一提交。主 Agent 调用生图工具，宿主完成描述准备后才创建图片任务；
  取消前置提交。重复工具调用复用同一准备/提交结果；分别描述的不同图片仍按原子请求
  序号和明确总量约束执行，不隐式重抽或择优。
- B-152/REQ-05 — 真实结果。卡片区分请求、来源和实际提交描述，显示真实模型/数量。
  助手不能用另一份构图冒充提交事实。重新生成沿用上次实际描述并创建新操作，不读取
  当前新笔记；编辑继续绑定确切版本。改用新内容需重新选源。
- B-152/REQ-06 — command/配置兼容。保留命令 ID/快捷键，捕获选区优先/否则命令所在
  笔记全文，打开同一 Chat 草稿，由用户发送；已有草稿或运行中请求不被覆盖。已有有效
  模型、数量、目录继续可用；内容配图使用可见的已存默认选项并允许修改，未改默认配置
  时仍一张。普通无笔记生图保留现有默认，当次参数不自动改写全局默认。生成原件先存
  Chat，每次用户选目标笔记后插入；配置目录用于正式附件，不自动迁移旧文件或自动插图。
- B-152/REQ-07 — 取消/恢复。准备可取消，撤销、取消或连接失效后迟到结果不能触发生图。
  准备失败与图片已提交分别呈现；重启不自动重跑准备/未知受理请求，原图片任务恢复
  查询/保存不变。本功能不新增持久正文副本，派生描述保留来源关系，不借再生成洗成无来源输入。
- B-152/REQ-08 — 低负担且可验证。Desktop 与 CLI mobile simulator 覆盖改动入口/来源
  控件；首用说明覆盖文字模型与 Wan 的接收内容及费用。复用既有卡片、编辑、保存、
  透明输入和清理能力；正常明确请求不增加逐次确认。

### Non-goals

- 新图片 provider、主动全库配图、自动识别/遍历章节、自动择优或隐藏重试。
- 第二套任务、通用 workflow/素材中心、独立 prompt 编辑器、重写主 Agent/Memory。
- 自动替换正文/frontmatter、自动插图、跨设备任务同步或放宽来源权限。

## User Flow And States

2026-10-06，Owner 确认紧凑的输入框布局：来源摘要、预览及全文/选区/移除操作默认
收起，通过 Create image 标题后的来源图标打开。模型和数量合并到左下方图片按钮旁的
单一设置图标，桌面与移动端默认均不常驻参数文字；点击后检查或调整本次参数，保留
普通描述与来源型请求各自已有的参数规则。移动端优先单行图标，实际空间不足时整组
换行，保留所有原有按钮与互不重叠的点击区域。打开入口和选择控件只操作草稿，不执行
模型或生图调用。

2026-10-06，Owner 选择结果区采用图片优先布局：所属助手消息内，图片任务卡片在前，
完整回复文字默认折叠；不删改模型回复或改变消息复制、保存、分享的内容。编辑、下载、
复制图片、保存图片到笔记使用单行图标，任务重新生成及回复文字操作通过更多入口访问。
任务参数、原始要求与实际提交描述默认折叠，并分别标注。生成中、部分成功、受理未知、
失败与透明背景确认仍显示真实状态及必要操作，不用虚构进度替代。
输入框的来源、关闭、底部工具和结果区图标按钮统一为 28px 可见尺寸；移动端保留约
44px 点击目标与足够间距，320px/360px 宽度下结果操作保持单行。图标入口提供名称；
带文字的停止、恢复及确认操作保留清楚的点击区域。

Chat 选择 CreateImage → 检查来源与本次选项 → 可选补充要求 → 发送。自然语言生图
继续由 Agent 判断；完整画面描述保持可用。用户明确指向笔记时，Agent 可先查找定位，
来源域按本轮范围/Data Boundary 读取并绑定真实快照，沿同一专用提炼链执行；不把模型
提供正文当作文件事实，不猜测当前页或直接发原问题。真实歧义或绑定与文字冲突先澄清；
只讨论/写 prompt 不生成。

笔记命令 → 捕获来源 → 打开预填草稿 → 用户发送。草稿已占用时保留原内容、提示处理后
重试。准备阶段由本轮拥有，受理后由现有持久图片任务拥有；状态明确区分正在构思、
已提交/生成中、结果与失败。

## Trust, Data And Authority

笔记文字是素材，其内嵌指令不能改变工具或授权。正文只发给已配置文字模型，准备好的
描述与明确参考图发给 Wan；选区不带全文，路径/标题仅作来源标记，不自动成为画面要求。
继承 DEC-043 的派生来源规则。来源选择不授予写笔记，保存仍每次显式选目标。

## Acceptance Criteria

| ID | 可观察通过条件 |
| --- | --- |
| B-152/AC-01 | 单一入口覆盖控件来源和明确自然语言笔记绑定；默认、预览/移除/切换、空输入行为正确；选择控件本身零模型/生图调用，无控件不阻断唯一笔记指代 |
| B-152/AC-02 | 发出后切换无关笔记仍使用原快照；选区外独有标记不进准备请求；失效/空/超限源不偷偷换源 |
| B-152/AC-03 | 专用请求实际使用原提示词基线、所选内容和补充要求；输出相关且有具体视觉构思；准备失败时 Wan 调用为零 |
| B-152/AC-04 | 准备完成前 Wan 为零，完成后 payload 等于准备结果；同操作只准备/提交一次；普通/参考/edit/不同主题多图仍正确 |
| B-152/AC-05 | 卡片与真实请求一致；重新生成不误用原问题/当前新笔记且保留来源；编辑目标正确 |
| B-152/AC-06 | 原 command 实际打开正确来源草稿、不直接生成、不覆盖已有草稿；有效旧选项可用；每次选保存目标且目录有效、不自动插图 |
| B-152/AC-07 | 准备期间取消/撤销/连接变化后无新生图；重载不重跑准备；旧任务可读，已受理/受理未知任务不额外生成 |
| B-152/AC-08 | Desktop 实际走过 @ 和 command，simulator 验证新增控件可达；少量真实模型证据证明专用提炼/提交链，费用授权和未测范围清楚 |

## Open Decisions

已确认产品范围无待选项。技术接线和兼容设计由当前图片架构维护；改变专用调用、来源、旧有效选项
或付费次数必须回到契约，worker 不得自行缩减。
