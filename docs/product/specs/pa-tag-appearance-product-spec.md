# PA Tag Appearance Product Spec

Document status: Approved
Updated: 2026-10-09
Work item: B-166
Decision: [DEC-056 — 显式启用的 PA 标签外观与稳定自动配色](../decisions/dec-056-opt-in-tag-appearance.md)
Authority: 本 feature 的用户行为、范围、非目标与验收标准；批准来源及实施边界见 DEC-056。

`Approved` 表示本会话已确认的产品选择形成稳定契约，文档状态本身不是实施或
验收证据。Owner 随后于 2026-10-09 明确授权完成开发测试，并在 GLM 限额期间
直接使用 GPT；十组 REQ/AC 验收完成后，又明确授权 closeout 与本地 master 提交。
当前技术契约与独有历史验证见文末；不含远程推送或 release。

## Problem And Product Outcome

- User problem: 用户希望正文、属性与 PA 中的真实笔记标签具有统一、柔和、紧凑的
  Notion 风格，同时保留原生标签行为和当前主题的控制权。
- Product outcome: 用户主动开启后，支持范围中的同名标签稳定采用同一色系；
  关闭后回到当前主题和 CSS snippets 的呈现，无需修改笔记或管理逐标签规则。
- North Star fit: 以可关闭的轻量外观降低视觉噪声，不给记录、编辑和回顾增加管理
  负担，遵守 [安静且可信](../pa-product-north-star.md#design-philosophy)。

## Scope

### In Scope

- **B-166/REQ-01 — 显式启用与设置持久化。** 提供默认关闭的开关；新配置及旧配置
  中缺失字段时均视为 `false`。仅在开启后接管本规范支持的标签外观。保存用户选择，
  重启、升级、视图重建和设置页面重绘不得自行开启、关闭或重置选择。
- **B-166/REQ-02 — 首版覆盖范围。** 支持正文阅读、Live Preview 和 Source mode
  正文标签、Properties 的 `tags` 属性及 PA 展示的真实笔记标签。排除标签侧栏、
  搜索与补全列表、普通 list 属性、PA 状态/来源/数量 chips；是否为真实笔记标签
  由数据含义决定，不能仅凭控件外形或通用 CSS 类判断。
- **B-166/REQ-03 — 标签身份。** 以完整标签名称作为配色依据，去掉语法前导 `#`，
  统一大小写，保留中文、`/` 与全部层级。父子标签各自计算，不继承颜色，不截取
  末级名称。规范化只服务于外观映射，不改写显示文本或笔记内容。
- **B-166/REQ-04 — 固定九色与稳定映射。** 同一规范化名称始终对应固定九色中的
  同一色系，不依赖标签出现或枚举顺序、其他标签增删、设备或重启。不同名称允许
  共用颜色，改名可能换色；不赋予颜色状态、优先级或类别语义。
- **B-166/REQ-05 — 形状与字体缩放。** 使用约 `3px` 微圆角、约 `2px 6px` 内边距、
  紧凑柔和的扁平标签，无阴影及常驻装饰边框。字号、字重和行高与所在界面协调，
  尊重用户字体与缩放设置；不将所有正文标签固定为 12px，不改变编辑行几何以追求
  完整矩形外观。保留可辨识的键盘焦点。
- **B-166/REQ-06 — 浅深色与可读性。** 浅色以本规范九组配色为参考；深色采用
  对应色系的暗底浅字。切换主题明暗不改变标签的色系归属；正文、悬停、选中和
  焦点等可见状态保持可读。普通标签文字以至少 `4.5:1` 对比度为验收目标，不能
  仅用颜色表达必要信息。深色具体 HEX 由当前 CSS 承接，实际合成状态见验收证据。
- **B-166/REQ-07 — 原生交互与移动端。** 保留正文中的 `#`、点击、搜索、光标移动、
  文本选择、输入与删除，以及 Properties 的新增、移除和键盘编辑。支持桌面与
  移动界面；长标签、中文、嵌套标签不得因外观改造遮挡相邻内容或破坏编辑操作。
- **B-166/REQ-08 — 生命周期与恢复。** 开关变更作用于已打开的支持表面，并由
  新建、重新打开的视图与其他窗口继承。关闭或插件卸载时清理本功能标记、监听、
  编辑器扩展及其外观作用，使当前主题和 CSS snippets 重新决定标签外观；不能
  回写出厂样式、残留着色或在后续视图重开时自行恢复已关闭功能。
- **B-166/REQ-09 — 数据与存储边界。** 本功能新增的持久化数据仅为外观开关，
  沿用 PA 现有设置存储。配色在本地完成；不新增 AI 或网络调用，不外发标签，
  不修改笔记、Markdown、Properties 数据或标签层级，不新增逐标签颜色表及
  持久化标签清单，不更改其他用户设置。
- **B-166/REQ-10 — 主题与宿主兼容。** 只在启用状态下对 REQ-02 的指定标签表面
  接管外观，不修改用户主题、CSS snippets 文件或宿主全局配置，不使其他界面的
  同形控件受影响。外观层沿用原生标签行为与渲染生命周期；具体宿主版本、主题
  冲突与编辑器接线由当前 Architecture 和真实交互证据说明，不以全局覆盖扩大兼容范围。

### Non-goals

- NG-01: 不提供逐标签颜色选择器、语义配色、父子继承、AI 分类或颜色规则管理器。
- NG-02: 不改造标签侧栏、搜索/补全列表、普通 list 属性或 PA 状态/来源/数量 chips。
- NG-03: 不隐藏或改写 `#`，不替换标签系统，不调整标签命名、层级或搜索语义。
- NG-04: 不为外观扫描并重写笔记，不新建标签数据存储，不增加网络或 AI 成本。
- NG-05: 不以本规范批准运行时代码实施、部署、Git 交付或发布，也不声明任意第三方
  插件及任意强制标签 CSS 覆盖均已兼容。

## User Flow And States

1. **关闭 / 尚未设置：** 用户看到当前主题和 snippets 的原有标签样式。安装或升级
   PA 不自动改变标签呈现；缺失字段与明确关闭具有同等行为。
2. **用户开启：** 持久化开启选择，在支持表面应用统一形状与自动配色。颜色由标签
   名称确定，不要求用户完成额外配置或逐标签确认。
3. **开启期间：** 用户照常输入、点击、搜索与管理标签。编辑、切换视图、打开新
   窗口或切换明暗模式后继续遵守同一名称映射；空标签集合自然保持空态。
4. **用户关闭或卸载插件：** 当前支持表面失去 PA 外观作用，恢复由当前主题和
   snippets 决定的呈现。再次打开视图或窗口不能重新应用已关闭功能。
5. **桌面与移动：** 产品行为一致；紧凑呈现必须兼容原有点击、触摸与编辑几何，
   不因视觉统一新增另一套标签操作方式。

## Trust, Data And Authority

- Source evidence: 产品确认来自 2026-10-09 本会话，完整归纳与边界见 DEC-056；
  本规范不引用不存在的外部批准记录。
- Data sent / stored: 无新增外发。仅持久化外观开关，使用已有 PA 设置存储；标签
  名称只参与本地外观计算，不新增逐标签持久化数据。
- User disclosure / confirmation: 开关清楚表达改变标签外观；默认关闭，用户主动
  开启就是该外观效果的授权，不引入逐次或逐标签确认。
- Reversibility / recovery: 关闭或卸载后清理本功能效果，当前主题和 snippets 恢复
  控制；原始标签与笔记内容始终保留。
- Implementation authority: 产品契约的批准与运行时代码实施授权分开；后续执行
  必须遵守实际用户授权；历史执行和 closeout 证据见文末，不由文档状态扩大授权。

## Acceptance Criteria

- **B-166/AC-01 → REQ-01：** 新配置、旧配置缺字段及明确 `false` 都不接管标签
  外观；用户开启/关闭后选择被持久化，重启、升级和设置重绘不改变其选择。
- **B-166/AC-02 → REQ-02：** 开启后逐一观察阅读、Live Preview、Source mode、
  Properties `tags` 及 PA 真实笔记标签，确认外观生效；排除表面与普通 list、
  状态/来源/数量 chips 保持原有行为和外观。
- **B-166/AC-03 → REQ-03：** `#Topic`、`Topic`、`topic` 使用同一配色身份；
  `项目/工作` 保留完整名称参与计算，父标签 `项目`、子标签 `项目/工作`、另一
  分支 `生活/工作` 各自计算。允许映射碰撞，不能用颜色恰好相同判定发生继承。
  显示文本、中文、`/` 和笔记内容未被规范化过程改写。
- **B-166/AC-04 → REQ-04：** 固定名称集合在不同枚举顺序、其他标签增删、重启
  及桌面/移动环境中保持同一色系；重复颜色合法，改名按新名称计算，映射没有
  附加语义规则或运行时随机性。
- **B-166/AC-05 → REQ-05：** 在实际支持表面确认微圆角、紧凑间距、无阴影和
  常驻装饰边框；改变字体与缩放后仍可读，正文行高、光标和相邻文本不受不合理
  固定字号或盒模型影响，键盘焦点可辨识。
- **B-166/AC-06 → REQ-06：** 浅深模式中同名标签保持同一色系，深色呈现为暗底
  浅字；对实际文字/合成背景及悬停、选中、焦点状态验证可读性与普通文字对比度
  目标。颜色差异不是理解标签内容或操作状态的唯一依据。
- **B-166/AC-07 → REQ-07：** 实际操作正文标签的点击/搜索、输入/删除、光标与
  选区，以及 Properties 的新增/移除/键盘编辑；桌面和移动界面均保持原生行为。
  中文、长名称和嵌套名称不遮挡相邻内容，`#` 保留。
- **B-166/AC-08 → REQ-08：** 在多个已打开视图/窗口中切换开关，再新建和重新
  打开视图，均遵守最新状态；关闭及卸载后不残留本功能标记、监听、编辑器扩展
  或着色。以启用中的当前主题和 snippets 为恢复基准，不能用出厂主题外观替代。
- **B-166/AC-09 → REQ-09：** 对照操作前后的笔记、属性与无关设置，均无改写；
  本功能只新增外观开关的持久化值，没有逐标签颜色表、持久化标签清单、AI 或
  网络请求。不得以只检查 UI 没有变化代替数据边界证据。
- **B-166/AC-10 → REQ-10：** 用实际宿主与代表性主题/snippets 场景验证开启范围
  和关闭恢复，不修改用户 CSS/主题文件及全局配置；范围外控件保持原状。记录
  真实冲突与未覆盖兼容性，不能把静态选择器命中或单一主题截图当作全面兼容。
