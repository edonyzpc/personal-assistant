# Pagelet 入口与阅读闭环 Product Spec

Document status: Approved
Updated: 2026-10-16
Work item: B-176
Decision: [DEC-066](../decisions/dec-066-pagelet-reading-loop.md)
Authority: 用户认可的第二轮入口、复访、阅读连续性及 PA Agent 交接行为；设计批准不代表实施或验证完成。

## Problem And Product Outcome

用户应能随时找到当前笔记的相关成果，安心读完并再次访问；需要深入时，把正在看的完整内容
交给 PA Agent。Pagelet 提供入口、阅读和来源连续性，Agent 自主判断发现与后续任务。
主动发现可以已经很深入，不要求用户先点击“深度发现”才允许产生高价值结果。

## Scope

### In Scope

- B-176/REQ-01：短点统一进入当前笔记内容，长按保留快捷操作。查看、复访和来源导航零模型调用；
  显式开始发现与阅读分开，沿用第一轮运行入口和权限。
- B-176/REQ-02：完整成果正文优先，来源可访问；多份成果独立可达并保持 Agent 交付顺序。
  同时支持已有内容和真实运行状态，不从缓存空、动画或已看状态推断“没有发现”。
- B-176/REQ-03：已看不妨碍复访。按笔记恢复仍有效的最近阅读内容、选中项和必要位置；
  仅实际打开的成果标已看，关闭不删除内容。同笔记新结果到达不抹除上次阅读快照。
- B-176/REQ-04：阅读中的正文、滚动和来源展开不被新结果/状态刷新打断；用户选择后切换。
  空阅读界面仅接入正在等待的同一次请求；晚到结果不重开已关闭界面，也不覆盖另一笔记。
- B-176/REQ-05：阅读锚点与活动笔记分离；Panel 与 Detail 保持选中成果和阅读归属。
  Detail 能独立交接；展开失败保留原阅读内容。
- B-176/REQ-06：选中成果以完整正文、原锚点和真实来源交给 PA Agent。附件可见、可移除，
  用户输入可编辑，不自动发送或覆盖草稿。获准正文实际入模，来源记录与消费状态一致；拒绝时保留附件并解释。
- B-176/REQ-07：沿用来源/版本、数据范围、provider、取消与效果权限；无论内容是联系、错字或修改建议，
  都不通过代码或提示词增加语义路线/价值门，不把附件视为执行授权。

### Non-goals

- 扩大 B-175 自主发现、暂存、检索恢复、上下文或模型能力验收；逐步曝光 run-local 暂存或内部过程。
- 永久保存、跨重载/跨设备历史、完整历史管理中心、Save 全面修复；读取编辑器未保存文本、选区或差量。
- 固定内容分类、质量评分/排序、语义拆分、专用修改建议 schema、自动应用或新的编辑器/权限框架。
- 全面重构 Pagelet/Detail、改变快捷操作能力、重做手势/几何、恢复已退役的范围控件或 generic preload。

## User Flow And States

短点当前笔记 → 取回有效成果与最近阅读 → 阅读正文/来源 → 可选择新成果、开始发现或与 PA Agent 继续。
后一动作先准备可见附件，用户发送后才进入 Chat 运行；后续任务内容由 Agent 理解。

| 情况 | 呈现与行为 |
| --- | --- |
| 已有成果，未运行 | 恢复上次仍有效的阅读；其余同批成果可访问 |
| 已有成果，同时运行 | 正文保持，附加真实活动状态；不强制回到加载页 |
| 无成果，正在排队/分析 | 显示真实阶段；同一等待请求完成后可填入正文 |
| 无可用成果，未运行 | 说明暂无可用内容并提供开始发现；不自动发起调用 |
| 正常无发现、失败、未完成、取消或来源失效 | 沿用第一轮真实终态，分别表达；可用旧成果独立保留 |
| 阅读期间有新结果 | 轻量提示“有新发现”，用户选择后切换，不自动抢焦点 |
| 关闭后重开 | 恢复仍保留有效的最近阅读；已看不会变成空态，也不承诺恢复已清理会话 |
| 来源失效 | 不继续以有效成果展示或交接；可保留阅读外壳和原因，其他独立有效成果仍可读 |

内容页不增加“相关/洞察/问题”固定分栏。打开来源 B 时仍明确正在阅读 A 的成果；
在 B 上再次短点才进入 B。桌面和移动采用同一语义，复用已有长按、键盘及阅读渲染能力。

## Trust, Data And Authority

复访与最近阅读状态只保留在现有插件会话内，seen 沿用设备本地记录；不新增正文磁盘副本、同步或后台恢复。
新集合不会仅因“更新”使旧阅读成果失效；来源、权限、pipeline、已有时效等真实边界继续适用。

交接只含可见完整文本及必要来源依据，不发送隐藏推理、工具日志或自动附带全部源笔记正文。
只读查看不会发送 provider 请求；显式发现及用户发送 Chat 仍按现有 provider 信任、告知和费用边界处理。
我的笔记/网络资料/综合模式与独立来源权限共同准入；不通过删引用、摘要或自动切换模式绕过混合来源限制。

Pagelet 成果复访及交接前沿用 current-evidence 校验。材料进入 Chat 后，按现有
[快照执行契约](./pa-agent-snapshot-execution-product-spec.md)处理当前生成、重试和下一 loop；
不因普通文件后续编辑撤销已接受响应。实际修改仍由 Operations 检查当前权限与目标冲突。
“与 PA Agent 继续”不自动修改；用户明确请求修改也不被额外强制成仅讨论或重复确认。

## Acceptance Criteria

- B-176/AC-01：立即短点和异步就绪回调都进入内容；长按快捷操作保留。缓存命中、缺失或不可用时，
  查看都不创建模型运行、不要求 AI 配置、不计分析额度、不抢占正在运行的发现。
- B-176/AC-02：同批完整文本及来源均可达；已有正文与运行状态共存，缓存未命中不显示模型无发现，
  运行失败不清除独立有效旧成果；内部暂存不提前显示。
- B-176/AC-03：已看后关闭重开、A/B 切换、同笔记新集合到达后重开，均能取回仍有效的最近阅读；
  只打开一份不会把其他份标已看，来源独立失效不重置其余成员身份。
- B-176/AC-04：新结果/活动更新不替换阅读正文、滚动或展开状态；用户明确选择才切换。
  关闭等待界面后晚到结果不重开；A 的异步结果不覆盖 B；真实失效仍阻止继续使用。
- B-176/AC-05：Panel → Detail 保持原锚点、选中全文和阅读位置；原 Panel 关闭后仍可继续到 PA Agent；
  目标打开失败保留原阅读，操作回调不依赖错误的界面生命周期。
- B-176/AC-06：带正常 Chat 来源选择的真实服务/运行时路径，把获准完整附件投影到 provider 输入；
  实际输入依赖、写作来源记录和附件消费一致。不兼容来源、忙碌、草稿冲突、失败或取消有真实反馈并保留适用内容。
- B-176/AC-07：交接内容维持 context-only 和真实来源；正文含修改要求不制造权限。后续明确操作沿既有 Agent/Operations
  边界执行；没有新增发现路线、数量、分类、评分或通过提示词恢复的旧约束。

## Open Decisions

没有阻止本轮设计的未决产品选择。实现授权及执行排期尚未授予；任何需要新增持久化、来源范围或权限的方案
都超出本轮，不能以实现便利代替用户决定。
