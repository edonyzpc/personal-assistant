# Ghost Blog Publishing Product Spec

Document status: Approved
Updated: 2026-09-29
Work item: B-153
Decision: [DEC-045](../decisions/dec-045-ghost-blog-publishing.md)
Authority: 已确认的 blog2ghost 首版目标行为、范围和验收标准，含 2026-09-29 原生预览与每次操作同桌面完成的修订；不是已交付能力说明。

## Problem And Product Outcome

将 Obsidian 原有笔记准备成 Ghost 可发布文章，自动处理格式、图片和渲染依赖。
正常流程只需看预览并确认，不要求用户复制 injection、修理图片路径或手工维护临时稿。
服务于 [North Star](../pa-product-north-star.md) 的笔记复用，不主动改写文章或推销发布。

## Scope

| Requirement | 已批准行为 |
| --- | --- |
| B-153/REQ-01 | 支持 `@blog2ghost 将当前笔记发布到ghost平台`、指定 `{note_path}`、指定 `{note_name}`。当前笔记在请求提交时绑定；同名歧义时询问，不猜目标。桌面先交付。 |
| B-153/REQ-02 | Obsidian 为内容主源。导出不改变正文、图片引用或普通属性；保留 Ghost 中可可靠对应的未变部分的格式调整。内容冲突或无法可靠对应时说明并暂停，不静默覆盖；需要重建时重新准备完整预览并由用户明确选择覆盖。 |
| B-153/REQ-03 | 转换正文、代码块、表格等常规 Markdown；按需支持 Prism、Mermaid、行内/块级数学公式。代码与公式原义不变。复用兼容站点配置，仅补充文章级注入，保留人工注入，避免重复加载。 |
| B-153/REQ-04 | 展开显式整篇/标题/块嵌入及所含图片。缺失、循环和来源排除阻止准备成功。普通双链不展开、不自动发布目标：已知已发布关联转换为博客 URL；锚点可靠时保留，否则退到文章 URL 并提示；未发布/缺失/歧义链接保留可见文字并提示。 |
| B-153/REQ-05 | 本地和网络图片上传/转存到目标 Ghost，优先复用同站已有 URL 和同内容资源，保留格式、质量、尺寸、替代文字与说明。下载或上传失败阻止准备成功；只替换导出副本引用。 |
| B-153/REQ-06 | 标题默认笔记文件名，可显式覆盖；仅同步明确配置的发布标签、封面、摘要。未配置表示不管理，显式清空表示清除。首次形成的 slug 后续保持，标题改名不改 URL。默认站点/访问范围预先配置，更新沿用原访问范围；范围变化单独确认。 |
| B-153/REQ-07 | 新文章准备为原始草稿，自动检查后提供 Ghost 编辑/预览入口，由用户在 Ghost 发布。已发布文章更新或恢复使用 PA 临时预览草稿，线上旧版不变；用户在 PA 确认后写回原 post。直接用 Ghost Preview 链接，在 Obsidian 原生 Web viewer 中查看并固定检查，保留系统浏览器入口，不另建预览页面。 |
| B-153/REQ-08 | 草稿受理即写回最小关联信息；正式发布后按远端实际状态更新记录。移动/重命名沿用关联，复制关联属性不自动取得覆盖权。每次发布、更新或恢复在同一桌面完成，支持同桌面重启后核实并继续；不跨桌面接续未完成操作。已完成基线与必要恢复快照随 vault 同步后，其他桌面可对同一文章发起新更新；缺必要记录提示先同步，不盲写、不自动接管。 |
| B-153/REQ-09 | 预览与提交绑定同一份内容、来源与站点配置。预览后内容/远端/配置变化重新准备并确认；超时先核实远端结果再重试，不能盲目创建重复文章。关键检查不可用时，新文保留草稿，已发布文保持不变。 |
| B-153/REQ-10 | PA 临时稿未确认时保留并复用；确认提交成功后清理对应、仍由 PA 管理的临时稿。失败或已被人为修改/发布时不盲删。提供撤销最近一次 PA 更新：预览更新前版本，确认后覆盖该次管理的正文/字段/PA 注入区域，不要求差异页或合并，Obsidian 当前内容不变。 |

### Non-goals

- 移动发布、旧 Ghost 文章接管/迁移、批量发布、多平台 CMS、定时发布和 newsletter 发送。
- Ghost → Obsidian 双向正文同步、自动润色/摘要/选封面、普通双链关联文章自动发布。
- 全站设置修改、任意笔记脚本执行、把整篇文章变成单个不可编辑 HTML blob。
- 通用历史版本管理、多人协作锁服务、每种主题/浏览器/Obsidian 插件语法的兼容承诺。
- 进行中发布的跨桌面接续、设备锁/永久设备绑定、同步进度监控与冲突自动修复。

## User Flow And States

1. 首次使用配置默认 Ghost 站点、访问范围和凭据。凭据由用户手动填写；新桌面单独配置，文章不需重新绑定。
2. 在本次操作的桌面调用 Skill，绑定唯一来源，处理嵌入/资源/字段，生成原草稿或专用临时草稿。
   引导用户在当前桌面完成本次预览与确认，不要求文章一直由该桌面维护。
3. PA 显示「草稿已就绪」或「更新预览已就绪」、检查结果、预览入口和下一步。
   新文章跳到 Ghost 完成 Publish；更新/恢复在 PA 点击对应确认按钮。
4. 暂时离开、取消或关闭应用不等于提交；在同一桌面下次显式使用/刷新时重新核对并继续。
   不依赖旧 Chat 历史或确认状态。另一桌面遇到可识别的未完成操作时，保留现场并引导回原桌面完成。
5. 新文是否已发布通过下次显式刷新/使用时读取 Ghost 确认，不持续后台轮询。
   Unpublish 由 Ghost 后台执行；PA 下次读取实际状态，保留原关联，不自动重新上线。
6. A 完成操作并保存已完成记录，记录随现有 vault 同步后，B 可以发起新的更新。B 读取必要
   基线与 Ghost 实际版本，重新检查来源、准备预览并在 B 确认。当前笔记包含新修改属于正常
   更新，不以「笔记必须等于线上旧版」判断同步是否完成；缺必要记录则提示先同步后再开始。

| 情况 | 用户看到的结果 |
| --- | --- |
| 缺图、正文/代码截断、Mermaid 或公式失败 | 明确指出位置/原因，状态不能为「就绪」；PA 不允许提交更新 |
| 高亮语言不支持，但代码完整可读 | 可继续，简要提示；不能把加载失败伪装成语言不支持 |
| 少量颜色/间距差异 | 可继续，必要时提示；不要求逐像素一致 |
| 新桌面缺少必要的已完成发布记录 | 提示先同步发布记录，不根据文章 ID 自动覆盖或重建历史 |
| 新桌面发现另一桌面的未完成操作 | 提示回原桌面完成；可打开已有 Ghost 入口，不接续、覆盖或删除该任务 |
| 网络结果不明 | 「正在核实」或「需要继续核实」，不是「失败所以重新创建」 |
| 已提交但清理失败 | 明确「更新成功，预览草稿待清理」，不回报更新失败或再次提交 |
| 发布后才发现渲染问题 | 如实说明已在线和问题，提供恢复入口，不声称尚未发布 |

PA 无法拦截用户自行在 Ghost 点击 Publish；检查未通过时只提供明确错误/修正入口，
不将该稿标为已验证可发布。生产环境实际访问控制以 Ghost 为准。

## Trust, Data And Authority

- 外发仅限用户选中的文章、显式嵌入、图片、明确发布字段和受管注入。SourceAccess、
  当前任务来源范围与排除规则覆盖每个依赖及恢复快照；笔记/网页/Skill 内容不能授予写入权。
- `@blog2ghost` 的显式准备请求授权所需资源上传、草稿写入与最小关联写回；正式更新和
  恢复必须来自对应版本的用户确认。浏览预览本身不表示确认。
- 图片二进制、Ghost 密钥、完整发布快照不送给模型；Agent 只接收定位与执行结果。
  正常笔记读取仍遵守既有配置的 AI 提供方边界，不因本 feature 扩大来源。
- 文章关联随笔记保存；已完成基线与必要恢复快照存于 vault 的 PA 管理区域，由用户已有
  同步方式带到其他桌面。候选、进行中请求、结果核实记录和确认状态不作为跨桌面同步数据；
  必要的本机记录支持重启恢复，重启后重新确认。不自建同步服务或同步状态机。
  说明快照包含文章历史内容；排除其作为普通 Memory/检索/再发布来源。
- 预览链接是可分享链接，持有者可查看；作为用户的操作入口显示，不进入公共文章、
  普通日志或模型上下文。管理凭据不进入链接、frontmatter、同步数据或导出内容。

## Acceptance Criteria

| Acceptance | 可观察通过条件 |
| --- | --- |
| B-153/AC-01 | 三种入口绑定预期笔记；同名提示选择；切换编辑标签不改变已受理目标；移动端无可执行写入口。 |
| B-153/AC-02 | 原笔记正文/图片引用无变化；未变且可对应的 Ghost 格式保留；实质内容冲突不被静默丢弃；重建覆盖需新的完整预览确认。 |
| B-153/AC-03 | 一篇综合夹具在真实 Ghost 主题中保留代码字符、图片、Mermaid 和两种公式；普通段落/代码在 Ghost 可编辑；无重复渲染库，全站配置无写入。 |
| B-153/AC-04 | 标题/块嵌入范围准确；排除、缺失、循环不外发；普通链接按目标状态转换或可读降级，不扩展内容。 |
| B-153/AC-05 | 本地/网络图片成功转存且重复准备复用；一次图片失败阻止就绪；凭据不随资源请求或重定向外泄。 |
| B-153/AC-06 | 未配置/显式设置/清空三态正确；原 URL、作者、访问范围和未管理字段保持；预览与提交的标签顺序等渲染字段一致；导出无内部 frontmatter。 |
| B-153/AC-07 | 新文只创建草稿；已发布文在预览和取消后仍为原内容；PA 确认才更新原 ID/URL；Ghost Preview 在原生 Web viewer 与系统浏览器两入口可用，固定检查读取对应网页，且没有邮件发送。 |
| B-153/AC-08 | A完整发布并保存记录，独立环境B取得源与完成记录后对同一ID/URL发起并完整完成新更新，B的新内容不被误判为同步失败；同桌面重启后重新核对来源和远端再继续。缺必要已完成记录/准入或复制关联冲突暂停；B不接续未完成操作，不依赖A的候选、执行进度、Chat历史或秘密配置。本轮按Owner批准的同机双vault方式验收，真实跨设备同步另行补验。 |
| B-153/AC-09 | 准备后变更、过期确认、重复点击、请求成功但响应丢失均不会错误上线或盲目重建；不可验证不声称成功；线上实际状态与提示一致。 |
| B-153/AC-10 | 恢复通过旧版预览确认直接覆盖对应范围，不改笔记；只保留最近一次可恢复更新；只清理确认归属的 PA 草稿，清理失败不重复提交。 |
