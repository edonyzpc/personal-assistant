# PA Recoverable Agent Execution Product Spec

Document status: Approved
Updated: 2026-09-24
Work item: B-144
Decision: [DEC-040](../decisions/dec-040-recoverable-agent-execution.md)
Authority: Owner 确认的用户行为、范围与验收标准；B-144 已完成实现、自动化验证与 Desktop test-vault 实际交互，本文不作为发布凭据。

## Problem And Product Outcome

- User problem: 正常长调用被短期限终止，可恢复工具错误过早结束，后台内容更新影响回答，writing 与普通 Chat 交付状态耦合。
- Product outcome: 一个主 Agent 在已获准边界内持续推进有限任务，交付真实结果；失败能够恢复，不能恢复时准确说明。
- North Star fit: 自然提问、少干预、有来源、持久动作可信；不要求用户理解工具协议或内部重试。

## Scope

### In Scope

- **B-144/REQ-01 已读材料**：普通 Chat 使用明确的已读材料版本；普通编辑、同内容背景刷新及背景版本更新不自动撤回回答。用户要求最新时重读相关材料。
- **B-144/REQ-02 动态授权与写入**：后续物理请求仍检查当前授权、排除及来源范围；派生摘要也受约束。写入核对目标版本；真实撤销不能被旧快照绕过。
- **B-144/REQ-03 自主恢复**：参数/输出错误、空结果、暂时失败可反馈主 Agent修正或改路；不以一次失败、固定特殊重试一次或提前移除工具替代恢复。
- **B-144/REQ-04 重复与副作用**：区分成功结果复用、失败重试和无进展；部分成功只恢复未完成部分；结果未知的副作用先核实，不盲目重做。
- **B-144/REQ-05 操作期限**：模型和普通同步远程工具单次尝试默认 30 分钟，可由具体能力覆盖；含响应读取。排队/退避另计，内外期限对齐；单次超时进入恢复。取消通用 60 秒静默终止和 180 秒总运行强制收尾。
- **B-144/REQ-06 完成目标与进展**：Chat/Pagelet 等 Agent 任务均以完成有限目标为主；后台不默认降低预算。正常长操作不是无进展，心跳或反复解释也不是任务进展。真实资源边界应给出原因及未完成事实。
- **B-144/REQ-07 Writing 领域化**：主 Agent 自行选择写作能力，按需准备领域上下文；普通回答不创建完整作品生命周期。保留 native 输出、预览、确切版本、续写、显式保存及旧 reader；可修正验证问题回到循环。

  2026-09-24 局部替代：其中“主 Agent 自行选择写作能力”是 B-144 当时的入口要求，已由 [DEC-042 的显式 Writing 决定](../decisions/dec-042-agent-task-source-boundary.md#2026-09-24-owner-补充写作由显式-chat-操作触发)替代。当前仅 `@Writing` 等显式操作或用户明确选择继续已有版本，才开启本轮写作上下文与作品交付；本条的作品生命周期和旧 reader 要求继续有效。
- **B-144/REQ-08 统一交付**：候选验证/必要提交成功后确定任务终态；正文、作品、历史与状态一致。无正文、未闭合协议、虚假保存声明不得被判完成；等待确认单独表达。
- **B-144/REQ-09 警告与限制**：成功恢复的问题只进入过程与 debug；剩余限制具体说明。必需目标未满足为部分完成/未完成，不用泛化 warning 包装成功。
- **B-144/REQ-10 并发与公平**：至少一个 Chat 与一个后台 Agent 能在资源允许时并行推进；等待释放不必要名额。冲突写入、VSS 队列仍协调；真实 provider 限制通过排队/恢复处理，避免任务长期饥饿。
- **B-144/REQ-11 等待与重载**：同次插件运行保留恢复上下文；用户可取消。重载后显示中断，由用户选择继续，复用安全历史/产物并先核实已提交操作；不自动重放。
- **B-144/REQ-12 观测与边界**：复用 run/turn/request/工具观测，区分排队、准备、实际发送、恢复、等待和交付；默认不记录正文、参数或秘密。Desktop 与 buffered/mobile 路径具有一致任务语义，原有功能及持久授权边界继续有效。

### Non-goals

- NG-01: 通用跨重启持久任务引擎、跨设备自动接管、定时重复执行平台。
- NG-02: 新增分类模型、每类任务一个 Agent、MCP/shell 扩展或更换 provider/model。
- NG-03: 删除全部保护、自动扩大来源、重复付费生成、取消写入确认，或绕过 Memory/VSS 写队列。
- NG-04: 改变 Pagelet anchor/质量/quiet no-insight，扩大独立后台提取与学习的授权。
- NG-05: 由本次交付推断未测的性能提升、真机移动路径或跨重载自动续跑。

## User Flow And States

用户在同一个 Chat 中提问，主 Agent 使用允许的材料与能力；选中文字仅表示提供材料。过程按需显示读取、生成、恢复或等待，不出现内部协议正文。

| 情况 | 用户看到的结果 |
| --- | --- |
| 工具失败后恢复成功 | 正常完成；不留下最终警告 |
| 主要任务完成、可选核对不足 | 结果与具体限制 |
| 必需材料缺失或动作未完成 | 已完成部分及尚缺事项；不误报全部成功 |
| 已请求确认但尚未操作 | 等待确认；取消不会产生未获准操作 |
| 暂时限流/远程任务仍在执行 | 真实等待状态，保持可取消，无反复弹窗 |
| 仅收到 thinking、空白或缺失的原生 tool call | 自动恢复或如实未完成，不以阶段结束显示任务完成 |
| 插件重载 | 未完成工作显示中断；用户选择继续，先核实可能已生效的操作 |

正常回答中合法的 `<tool_calls>` 示例不因字符串匹配被删除；真正的协议异常由响应适配层识别。页面中的 Thinking 阶段不能充当任务完成事实。

## Trust, Data And Authority

- 已读快照记录实际使用的材料和来源，不复制整个 vault、不阻塞后台维护。新读取可引入新的获准版本；引用不得假装代表交付瞬间的最新文件。
- 内容变旧与授权撤销分离。关闭新提取不自动等于撤销已有 Personal 读取；Memory 主控制、Forget、排除及本轮范围仍按既有治理解释。
- 不新增外发目标或后台学习。恢复可能增加正常模型/工具调用；30 分钟是操作期限，不是额外付费操作许可。
- 原有写入确认、目标冲突、Undo、操作审计和图片 submission_unknown 保护不变。
- debug 默认只存内容无关的标识、阶段、时长、状态和错误类别；快照正文留在既有上下文生命周期，不建立新的原始请求/响应日志仓库。

显式 Debug 的已交付数据边界由 [DEC-041](../decisions/dec-041-agent-debug-view-and-local-history.md)
及 [B-145 合同](./pa-agent-debug-view-product-spec.md) 承接：过滤后的正文/Prompt 本机有界保留，
reasoning 留在会话内，并联动删除。不改变本节对 B-144 默认内容无关观测的描述；
Debug 关闭不采集原始内容、观察失败不影响执行等约束继续有效。

## Acceptance Criteria

- **B-144/AC-01**：读取后编辑笔记、Memory 变黄或刷新背景，本轮可基于已读内容完成；明确要求最新时取得新内容，且不混淆版本来源。
- **B-144/AC-02**：准备到实际发送之间撤销权限，初次请求、SDK 重试及摘要均不发送不获准材料；写入目标被编辑时不覆盖；纯新鲜度变化不误当撤销。
- **B-144/AC-03**：错误参数及不合法写作候选可被反馈并修正；首次检索失败可改用其他获准路径，工具保持可用。
- **B-144/AC-04**：相同参数的临时只读失败可重试；有效成功结果可复用；部分成功及结果未知的副作用不会重复执行。
- **B-144/AC-05**：虚拟时钟证明超过 60 秒/180 秒及健康五分钟调用不被旧期限终止；默认尝试在 1,800,000 ms 到期，覆盖值及 streamed/buffered 路径生效；到期进入恢复，取消不等待到期。
- **B-144/AC-06**：有新证据/子目标完成的多步任务继续；重复同因失败触发改路，持续无进展如实收束；等待限流不冒充进展或无限扩大目标；后台不因身份提前收尾。
- **B-144/AC-07**：普通问答不创建 writing 版本/预览会话；显式或语义写作可生成、纠正、预览、续写并显式保存；已有版本与旧历史可读。

  2026-09-24 局部替代：其中“语义写作”作为隐式入口的验收条件已失效；当前入口按 [B-146/AC-07](./pa-agent-task-source-boundary-product-spec.md#requirements-and-acceptance)验收。普通问答不建作品、显式写作后的作品交付及旧版本可读要求仍适用。
- **B-144/AC-08**：空白、仅 thinking、缺失原生调用、无效候选不能显示完成；确认卡不冒充保存；终态、正文、产物和重载后历史一致。
- **B-144/AC-09**：已恢复错误不留下最终 warning；未核实的可选内容明确说明，必需任务未完成不误报成功；过程仍可在 debug 定位。
- **B-144/AC-10**：可并发 provider 夹具中 Chat/后台同时推进，双方公平；退避/等待确认不占无用名额；同目标写入及 VSS 操作仍互斥，未知副作用不因名额回收被重放。
- **B-144/AC-11**：运行内恢复保留上下文；关闭视图/取消/卸载按既有任务归属清理；重载不自动续跑或重放；用户继续时核实已有操作，缺失进度不伪造成已完成。
- **B-144/AC-12**：debug 关闭无原始内容采集；观测失败不改变执行。Desktop 实际交互覆盖编辑→Memory 更新→提问、选中文字分析、写作、等待取消和历史；buffered 路径另有适配器证据，不把模拟器称作真机。

## Open Decisions

None. 30 分钟、前后台完成导向、受控并发、重载后由用户继续均已明确并交付；工程细节见当前 Architecture，不能据此扩大上述范围。
