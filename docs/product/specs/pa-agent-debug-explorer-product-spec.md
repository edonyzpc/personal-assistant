# PA Agent Debug Explorer Product Spec

Document status: Approved
Updated: 2026-10-10
Work item: B-167
Decision: [DEC-057](../decisions/dec-057-agent-debug-explorer.md)
Authority: Owner 已确认的桌面/移动预览及“聚焦展开＋节点定位搜索”组合；本文持有长期产品行为，当前实现由 Architecture 持有，终态验证见历史证据。

## Problem And Product Outcome

用户要完整观察 Agent 从接收请求、每轮准备、模型调用和工具执行到结束的过程，并快速解释某个节点的输入、结果、重试和耗时。当前事件分页、方块和上下布局使运行结构及阅读位置不稳定。

目标是一个可持续浏览的完整运行大纲，配合可信时间轴和方便的节点详情。遵循 [North Star](../pa-product-north-star.md) 的“安静且可信”：只有用户进入 Debug 才展开诊断信息，不增加普通 Chat 负担，不调用模型生成解释。

本规格接续 [B-145](./pa-agent-debug-view-product-spec.md) 的查看布局/导航，并落实既有全过程可观察要求；[B-165](./pa-agent-snapshot-execution-product-spec.md) 的数据与执行边界不变。

## Scope

| ID | Requirement |
| --- | --- |
| B-167/REQ-01 | 所选 Run 的全部已记录 Turn、关键阶段、逻辑调用、物理 attempt、工具与无 Turn 阶段都可达。节点树、搜索和轮次导航覆盖整个 Run；不能因 200/500 条内部页或实时尾窗遗漏早期/中间部分。补齐实际发生的关键观察点，缺口单独说明 |
| B-167/REQ-02 | 层级、排序、时间和状态来自执行事实。重复更新合并，真实重复阶段/重试各自保留；统一 Run 时间尺度表达串并行。未知时间/usage 不填零，父子 usage 不重复累加，恢复成功不抹去失败尝试 |
| B-167/REQ-03 | 宽容器采用树形行＋时间轴＋右侧节点详情；轨迹/详情独立滚动，可调整分隔，历史可收起。窄桌面 leaf 与手机均能使用，不依赖整个窗口宽度 |
| B-167/REQ-04 | 默认聚焦展开当前执行或选中路径，全部 Turn 入口保持可达，辅助阶段与 attempts 可折叠；祖先提示失败/重试/缺口，支持手动展开全部。用户展开选择不随刷新重置 |
| B-167/REQ-05 | 当前 Run 的节点定位搜索覆盖名称、工具、阶段和已记录错误摘要，保留祖先路径及命中数/无结果状态。清空恢复普通展开状态，不为搜索读取完整正文或建立全文索引 |
| B-167/REQ-06 | 移动/窄容器为轨迹页与整页详情；节点名称/状态/耗时在主行，时间条在第二行。折叠和选择分开命中；历史/轮次弹层、返回恢复、当前可见序列的前后节点导航完整可用 |
| B-167/REQ-07 | 新事件更新事实，不抢用户的 Run、节点、搜索、折叠、正文展开与滚动位置。用户手动浏览暂停跟随，明确“跟随最新”才恢复；暂停不停止采集或 Agent |
| B-167/REQ-08 | 详情按节点类型呈现真实输入/Prompt、输出、provider reasoning、工具 IO、耗时/usage、过滤后的错误与原始已记录字段。长内容按需读取/展开；未加载、未采集、未提供、过滤、容量缺失、已清理分别表达 |
| B-167/REQ-09 | 复用现有入口、开关、会话/结果历史筛选与显式清理。旧历史仍可浏览；清理/Forget/过期同步撤下失效可见内容，迟到查询不得恢复它；关闭视图只释放查看资源 |
| B-167/REQ-10 | 保留本地有界数据与执行隔离，完整大纲不意味着一次渲染全部正文；采集/读取/渲染失败不能改变 Agent 结果。长任务与实时更新时仍可操作原生 tab、编辑、保存、Stop 和 Debug 导航 |

### Non-goals

- 本次核对已确认关键阶段及实际修改的观察接线，发现具体漏点再补齐；不开展所有业务执行分支的全面采集审计，也不以此作为双端界面开发前置。全部已记录节点仍须完整可达。
- 跨 Run 或全文搜索、导出/上传、遥测平台、跨设备同步、永久归档、媒体副本。
- 从 Debug 重跑、重放、修改输入或执行工具；独立 Pagelet/Memory 后台任务自动全量记录。
- 推断模型内部思考、补造未观察历史或增加总结请求；强制采用 AgentPrism/LangChain/LangSmith。
- 改变 Agent、Host、工具或业务操作的授权、调度、完成判断与恢复规则。

## User Flow And States

### 入口与运行选择

沿用 Chat Debug 按钮与已有历史查看命令，复用本 vault 的 Debug tab。首次进入定位当前 Chat 的活动 Run，否则最近历史；无记录时解释现有开关，中途开启明确“从此处开始记录”。用户主动选择历史后，新的运行不能把它切走。

概览显示运行结果、时间、模型、已知 usage 和采集完整性。历史保持会话/结果筛选、分页与清理入口；分页只用于运行列表，所选 Run 大纲连续可达。Run 正在加载时显示“正在加载轨迹”，不得将已载入片段称为全部，也不能将读取失败称为无节点。

### 桌面与窄容器

```text
宽容器：运行选择／运行概览／采集状态
        ┌ 轨迹工具栏、搜索 ──────┬ 节点标题与概览 ─────────┐
        │ 树形名称   共同时标    │ 输入/输出/详情内容      │
        │ Turn / 阶段 / 调用    │ 独立滚动                │
        │ 独立滚动              │                         │
        └───────────────────────┴─────────────────────────┘
窄容器：运行概览 → 轨迹页 → 点击节点 → 详情页 → 返回轨迹
```

树行以缩进、类型图标、状态文字和时间条表达；不使用方块布局位置暗示并行。分隔拖动不能遮住详情或使轨迹不可用；宽度不足自动使用窄容器模式，保留节点与阅读状态。状态不单靠颜色表达，键盘可展开、选中、调整分隔并返回。

### 聚焦展开与搜索

首次展示运行大纲，展开当前执行路径；完成的历史按所选节点路径展示。无选择时优先已有失败/缺口位置，否则末个已观察执行节点。所有 Turn 及无 Turn 阶段有入口，折叠行保留异常提示；“展开全部”展开结构，不预读所有正文。

搜索作用于整个已加载完成的 Run 节点元数据；加载期间提示范围尚未齐全。结果是匹配节点与祖先路径，匹配和上下文祖先有区别。搜索暂存普通展开状态，清空后恢复；不能用返回第一页替代全 Run 搜索。

### 移动详情与导航

轨迹主行名称最多两行，状态/耗时不覆盖名称；第二行使用同一 Run 的时间尺度。折叠箭头与节点选择各有至少 44×44 CSS px 的独立触控区域，互不误触。

点击节点进入整页详情。直接返回恢复原搜索、折叠、节点和滚动锚点；详情“上一/下一”使用进入详情时固定的可见/过滤序列，首尾禁用，不因实时新增事件插入目标。主动换到另一个节点后，返回可定位该节点。清理移除的节点从序列撤下，不能保留已失效内容。

历史与轮次导航使用可关闭弹层，背景不可误操作，关闭后焦点返回触发点。轮次跳转、跨搜索查看失败请求属于显式定位；若需要离开搜索，按钮/提示必须说明“清除搜索并查看”，然后建立新的可见序列。

轨迹页与详情页各只有一条底部导航，保留安全区和末项空间。最后一个节点、最后一段正文、弹层最后一项都能滚到可读且可点击的位置；不以元素存在代替可用性验证。

### 跟随与状态

用户选择旧节点、搜索、手动折叠、滚轮/触摸/键盘滚动后暂停跟随。新事件仍更新节点事实及提示；恢复仅由明确“跟随最新”触发。程序定位滚动与用户滚动分开，不能互相触发跟随震荡。

Agent/节点结果、采集状态、详情可用性为三个维度。进行中只显示已经发生的阶段，不预知最终时长、结果或 usage；等待确认不等于业务成功，provider 完成不等于 Chat 已交付。中途开启、停止采集、容量丢失、存储不可用、旧格式与运行结束分别说明。

## Trust, Data And Authority

沿用 DEC-041 经 DEC-055 修订后的边界：Debug 显式开启才采集，正文/Prompt、实际 reasoning 与完整工具 IO 留本机有界历史；凭据/认证字段过滤，媒体仅引用、类型和指纹。运行内关联调用才属于此 Run。

“原始字段”指已记录且经过现有过滤的数据，不是完整原始 HTTP 请求或凭据出口。搜索不触发正文加载，查看历史不读取当前笔记来重建过去输入。UI 本地状态不写入 vault/同步设置，不新增网络或模型调用。

最多 30 天及现有容量规则、删除对话/Forget/清除 Debug、迟到写入屏障继续生效。普通来源配置、文件编辑/删除不追溯抹去历史；明确删除与治理动作按当前 owner 执行。故障如实显示，不影响 Agent。

## Acceptance Criteria

| ID | Acceptance |
| --- | --- |
| B-167/AC-01 | 多 Turn、超过旧 200 条窗口和 500 条尾窗、稀疏 seq、跨页更新与写入在途的 Run，稳定读取后所有实际记录节点可达、可搜索；无 Turn 阶段保留。加载失败/采集缺口不伪称完整 |
| B-167/AC-02 | 用代表性的受控执行及已有有效用例覆盖接收/排队、准备、逻辑调用/多 attempt、并行工具、重试/回退、等待/结束；节点身份、父子、真实重复阶段和边界正确，生命周期镜像不重复成假阶段；不枚举所有业务分支组合 |
| B-167/AC-03 | 已知串并行时间对应统一坐标；缺起点/结束时不推算区间，但保留 owner 已提供的有效耗时；buffered 路径与提前停止消费保留对应时间语义。父子与累计 usage 不重复相加，失败后成功仍可查失败节点 |
| B-167/AC-04 | 宽 leaf 树与右侧详情独立滚动，调整分隔、键盘操作可用；缩到窄 leaf 转独立详情页，选择不丢失，未发生内容横向挤压或控制遮挡 |
| B-167/AC-05 | 聚焦展开保留全部 Turn 入口及异常提示；展开全部可达末节点。搜索命中早期/晚期节点、保留祖先，清空恢复原展开；查询不调用正文读取或外部服务 |
| B-167/AC-06 | 移动端折叠与选择不误触；搜索→详情→返回保持位置；前后导航按固定可见序列、首尾禁用；明确清搜索跳转一致。底栏/安全区不遮末项，弹层关闭及焦点返回正确 |
| B-167/AC-07 | 连续新增事件期间浏览旧 Run/节点、展开正文、手动滚动都不丢状态；触摸与滚轮均暂停跟随，明确恢复后定位当前路径；详情不提前显示终态 |
| B-167/AC-08 | 不同节点显示各自真实输入/输出/工具/错误/usage；长文本可逐步读完，reasoning 与正文分开；无数据与未加载、缺失、过滤、已清理有明确区别 |
| B-167/AC-09 | 旧记录无需迁移重录即可读取，缺字段如实显示；浏览/读取途中清理或 Forget 后立即失效且迟到结果不恢复；reload、关闭 tab 和 Debug 开关维持原语义 |
| B-167/AC-10 | 相同受控输入对比 Debug 关闭、后台采集、实时查看，Agent 请求/工具效果不增加且结果不受观察故障影响；长任务仍可使用原生 tab/编辑/保存/Stop 与 Debug，实际 app 几何/交互证据覆盖桌面与移动模拟器 |

## Open Decisions

无阻止本规格成立的未决产品选择。具体组件拆分、缓存大小/批次、容器断点和必要的视窗渲染属于 SDD 工程参数，以真实输入和交互验证确定，不能改变上述范围。
