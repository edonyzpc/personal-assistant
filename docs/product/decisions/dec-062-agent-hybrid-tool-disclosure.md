# DEC-062 — PA Agent 工具混合披露

Decision ID: DEC-062
Status: Accepted
Updated: 2026-10-11
Work item: B-172
Authority: 用户确认混合管理方向、四项指标和两处审查修订；2026-10-11 进一步授权按优化后的方案与 SDD 开发及必要测试，保持范围精简。

## Context

工具接口与配套指导占据首轮请求的较大部分，但单项任务通常只用部分能力。B-171 已精简提示内容；其历史 M1 请求仍有 26 项原生声明、17,540 个序列化字符，占该请求字符约 38.1%。这不是固定工具总数，也不证明 B-172 的实际收益。Pi 研究、合并检查与历史派生字符依据保留在 [B-172 验证记录](../../archive/2026/b172-agent-tool-disclosure-validation.md#研究与取舍依据)。

当前 `c7ad470e` 已包含 B-170 独立计算，主 Chat 已实现接口并集为 36 个名称，不能沿用初稿的 35 项基线。加载在此指模型可见的 schema 与指导，不涉及插件模块初始化。

## Options

| 方案 | 主要取舍 |
| --- | --- |
| 全量常驻 | 无发现往返，但为未使用接口持续支付上下文成本 |
| 全部先搜索再加载 | 首轮更短，但普通读取也多一轮；检索排名和语言适配增加复杂度 |
| 基础直供＋完整短目录＋批量精确加载 | 普通任务直接调用；专用能力多一次发现机会，必须核算整项任务成本与等待 |

选择第三项。保留基础 `search_vault_metadata`，避免普通中文标题／关键词找笔记必经发现轮。其历史组件净增 698 字符是合理取舍依据，不是实测加速结论。

## Decision

1. 六项基础直供：`query_notes`、`read_note`、`search_memory`、`get_current_note_context`、`load_skill`、`search_vault_metadata`。另保持 [DEC-061](./dec-061-independent-agent-computation.md) 已交付的 `execute_code` 直接可用，均与当前真实可用条件取交集。
2. 其余当前可用能力进入完整短目录；仅在有待加载项时披露 `load_tools` 及配套指导，按精确名称一次加载多项，后续请求提供原生接口及配套指导。真实 command／图片／Writing／结构化来源绑定可预披露，不按用户文本关键词或额外模型路由。
3. 披露只影响模型看到的接口。当前权限、来源、身份、版本、取消、预算和领域效果仍由原 owner 判断；合法未披露调用不新增“必须先加载”的拒绝。加载参数被 Host 拒绝时保留有限纠错反馈及原输入依赖，不引入新的恢复机制。
4. 状态仅在当前 run 内累加；下一用户 run 重建。纯输出、final-only、当前真实效果与恢复事实保持既有合同。
5. 本期不合并或删除工具，不改 Pagelet、计算沙箱、领域权限或业务流程；不新增路由器、持久状态、设置项或评测平台。
6. 效果按首轮声明、普通任务往返、整项成本、能力选择正确性判断。离线机制回归、最多五对模型任务、一个实际 Chat 加载场景分层承担证据；不以重复采样取得 PASS。

本决定已由 B-172 实现，局部接续 [DEC-060](./dec-060-agent-prompt-progressive-disclosure.md) 中“当前允许工具全部常驻”的披露选择，保留其余 prompt 分层和来源合同。历史 B-171 验证不会被改记为 B-172 验收。

## Consequences And Revisit

专用任务可能增加一次模型往返；完整短目录和加载协议也有成本。首轮变小不能单独证明运行更快或整项更省。基础任务新增发现轮应为零，领域选择及实际结果不能因节省上下文退化；成本与等待冲突须展示具体证据后决定是否调整基础集。

只有真实任务显示目录选择困难、某个按需能力的额外往返不划算，或当前规模使目录本身成为主要负担，才重审名单或发现方式。回退仅撤回披露差量，恢复全量导出与指导；领域工具、用户数据和 B-170 不回退，也无永久加载状态需要迁移。

B-172 于 2026-10-11 按用户授权完成 closeout；实际四项结果、组合门禁、P2 窄修及证据限制见 [验证记录](../../archive/2026/b172-agent-tool-disclosure-validation.md)。当前实现约束由 [Product Spec](../specs/pa-agent-tool-disclosure-product-spec.md)、[Agent Architecture](../../architecture/pa-agent-architecture-plan.md#capability-model)、源码与 focused tests 持有；Accepted 不代替验收，也不表示已经发布。
