# DEC-066 — Pagelet 入口、阅读与 Agent 交接闭环

Decision ID: DEC-066
Status: Accepted
Updated: 2026-10-16
Authority: 用户在第二轮连续讨论中认可短点阅读、长按快捷操作、已看复访、稳定阅读与完整 Agent 交接，并于 2026-10-16 要求独立方案与 SDD；随后明确授权按 B-176 完成全部开发测试。执行结果由 Tracker 承接，Git 交付另行授权。
Work item: B-176

## Context

第一轮 [DEC-065 / B-175](./dec-065-pagelet-autonomous-discovery.md) 负责自主发现、可选完整文本暂存、
事实校验与最低交付。第二轮解决用户如何找到、读完、再次访问这些成果，并将选中的内容交给 PA Agent。
内容可以是旧笔记的新联系，也可以是错字、表述问题或高阶优化建议；这些例子不成为分类、优先级或配额。

源码基线 ecddc088：未看提醒选择器会推进候选并过滤已看内容；缓存按笔记保存最新集合；
普通后台接纳已经不会直接替换打开的正文，但界面刷新和显式运行晚到仍有阅读连续性缺口。
Panel 展开后的 Chat 回调仍依赖原 Panel 打开状态。正常 Chat 来源选择还会使 Pagelet 正文
在运行时投影前被排除，附件可见不能证明实际入模。具体证据见第二轮 SDD。

## Options Considered

| Option | Benefits | Costs / risks | Decision |
| --- | --- | --- | --- |
| 只改短点目标，继续共用未看候选和最新缓存 | 改动较少 | 已看、复访、晚到结果及实际入模问题仍存在 | 不采用 |
| 建立完整发现历史、分类中心和专用修改建议工作台 | 可承载更宽场景 | 增加持久化、管理成本和未批准能力 | 本轮排除 |
| 复用成果缓存，分开提醒、阅读与运行状态，修通现有 Agent 交接 | 覆盖已认可的完整用户旅程 | 需要少量阅读状态与跨模块来源衔接 | 采用，独立第二轮 |

## Decision

1. Pet 短点始终进入当前笔记的相关内容阅读，长按进入既有快捷操作。短点、复访和查看来源
   不隐式发起模型分析；已有内容直接呈现。显式开始发现仍走 B-175 的运行入口。
2. 阅读正文以 Agent 交付的完整文本为主，来源作为可展开、可打开的依据。同批多份文本保持
   原始交付顺序和独立身份，不按标题重新拆分，不增加固定分类、语义排序或新数量上限。
3. 已看仅抑制主动重复提示，不清除可读内容。按笔记保留最近阅读快照、选中项和必要位置；
   普通重开恢复仍有效的上次阅读，列表出现不批量标已看，关闭不等于不喜欢或删除。
4. 新结果只更新可用成果和轻量提示；阅读中的正文、位置和来源展开不被替换。仅当空阅读界面
   仍等待同一次请求时，完成结果可自动填入。关闭后不因晚到结果重新弹开；关闭阅读不隐式取消 Agent。
5. 编辑器活动笔记与阅读锚点分开：打开 A 的来源 B 时仍可读 A；在 B 上短点才进入 B。
   Panel → Detail 转交选中成果及阅读归属；Detail 的操作不依赖原 Panel 存活。
6. 已有成果与运行状态可以并存。状态来自真实调度/运行终态，缓存未命中不等于模型无发现；
   失败不清除独立有效旧成果。来源或权限实际失效继续按既有边界处理，不借稳定阅读恢复失效内容。
7. 从选中成果进入 PA Agent，保留完整正文、原锚点和必要来源事实，显示可移除附件及可编辑输入；
   不自动发送、不覆盖草稿。来源准入、实际模型投影、回答来源记录和附件消费必须一致。
   不兼容的来源不能静默丢弃、改写后放行或自动扩大范围；未接纳附件保留并说明原因。
8. 附件保持 context-only，不夹带隐藏推理或工具日志。继续探索和理解建议由 Agent 决定；
   用户明确要求修改时沿现有 Operations 合同处理，不增加专用写入协议、语义分类器或重复确认层。

### 2026-10-16 评审后补充选择

用户在 `67ab2183` / `cbf87d1a` 评审后明确选择并授权以下修复，要求必要范围与定向回归，暂不提交：

- 已被 Chat 接纳的 Pagelet 原文随当前聊天保存，重开后仍可引用。复用聊天的本机存储和删除生命周期；
  历史只携带材料引用，由 Agent 按需取回全文，不在每轮重复注入，也不建立独立 Pagelet 历史中心。
- 来源正文变化或既有时效失效时，保留会话内阅读正文和位置，提前标明来源已变化并禁止再次交接，
  提供显式重新发现入口。权限撤销继续阻止读取；陈旧快照不能被表示为仍有效的新成果。
- 阅读与首次交接复用实际输入来源校验；较早成果不能附上同次运行稍后才获得的网络来源。
  已接纳 Chat 材料按快照生命周期处理，普通源笔记后续编辑不删除已接纳材料，后续读取仍核验当前来源权限。

此选择接续下文原“仅会话阅读、无正文持久副本”的范围，持久化例外只覆盖用户实际交给 Chat 的材料。
回退时保留已存聊天数据，停止新附件写入及读取接线，不清理用户聊天或改写历史批准。

## Supersession And Unchanged Boundaries

本决定局部接续 [DEC-025](./dec-025-consumption-aware-pagelet-delivery.md) 的“空态已解释后短点转 Ring”目标；
保留设备本地 seen、主动提示去重，以及四项快捷操作的能力和布局。DEC-035/DEC-052 的兼容命令、
Open Pagelet 零调用边界及共享来源权限保持。本决定是待实施目标，不改写历史验证或当前代码事实。

B-175 的任务、测试与状态不变：第二轮接收终态校验后的完整集合，不展示 run-local 暂存半成品，
不改变自主探索、检索恢复或第一轮提示词。交接来源补齐归 B-176，不反向追加 B-175 验收。

## Consequences

- 复访覆盖当前插件会话内仍保留且有效的成果及最近阅读快照；不承诺跨重载、跨设备或历次生成档案。
- 沿用现有缓存、渲染、调度及来源准入；新增状态只服务实际阅读与交接，不建立通用结果总线或历史中心。
- Pagelet 交接前保持其 current-evidence 校验；Chat 接纳后的生成、重试及下一 loop 遵循
  [DEC-055](./dec-055-agent-snapshot-execution-and-debug-history.md)，不新增在途文件变化撤销规则。
- B-141 的 Detail 交接缺口由本轮范围承接，完成后再依真实证据处置；B-002 仅有局部重合，不整体重开或关闭。
- 设计时 B-175 占用唯一 Next；其后 B-175 已验证并本地提交，本轮取得实施授权，原 SDD 已迁入 Active，执行状态唯一见 [Tracker](../../development/active/pagelet-reading-loop/tracker.md)。

## Revisit Trigger

真实使用证明会话内复访仍丢失内容、阅读被异步更新打断、选中内容与实际入模不一致，或合法来源无法交接时，
修复对应链路。跨重载历史、专用修改流程或新数据范围需独立决定；模型未产生预设洞察不构成增加语义规则的理由。
